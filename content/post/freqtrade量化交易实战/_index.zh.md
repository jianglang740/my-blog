# Freqtrade 量化交易实战

这是我在学习 [Freqtrade](https://www.freqtrade.io/) 过程中整理的一套完整教程，共 **30 课、36 篇**，累计约 **69.5 小时** 的实践内容。

课程从零开始：先搭好环境和回测流程，再逐步进入参数优化、策略评估、实时信号与实盘交易，最后延伸到机器学习增强策略。每一篇都配有可直接运行的命令和代码，可按照课号顺序阅读。

> **阅读方式**：每篇末尾都有「课程导航」，可以直接跳上一课 / 下一课。配套的策略代码集中在 [Freqtrade 策略库](../freqtrade策略库/)，课程中提到的策略都可以在那里找到完整实现。

## 学习路径建议

1. **第 1–4 课**先把环境跑通，不必急着理解每个参数——能成功回测一次就是这一阶段的胜利。
2. **第 5–10 课**是回测的核心，重点是把「读回测报告」变成习惯，而不是只看收益率。
3. **第 11–15 课**引入参数优化和评分体系。这一阶段最容易过拟合，建议配合 [第 22 课](22-实盘前检查清单/) 一起看。
4. **第 16–19 课**把机器人接上通知和可视化，开始有「在运营一个系统」的感觉。
5. **第 20–24 课**进入实盘前的准备，**务必先用 Dry-run 跑够时间再投真钱**。
6. **第 25–30 课**是风控、心态与进阶策略。课程里反复强调的一点是：**风控比策略更重要**。
