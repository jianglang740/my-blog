- **真正连续的时间序列是理论上任意时间戳都有其对应的意义，这在现实金融世界中不存在，实际分析中可以采用等差分析法**

## 将价格转换成收益：

- 现实中的资产价格通常是不稳定的，其波动大小也不一致，两个或多个金融资产的时间序列通常难以放在同一张图表里进行比较，这时可以考虑将价格序列转换成收益序列，这样做的好处是简单平稳化、归一化；

- 将价格转化为收益通常分为简单收益和对数收益两种方法：

- 设：
- $P_t$：**t时刻资产价格**
- $P_{t-1}$$：**t-1时刻资产价格**

### 简单收益率（Simple Return）:

$$
R_t = \dfrac{P_t - P_{t-1}}{P_{t-1}} = \dfrac{P_t}{P_{t-1}} - 1
$$

- 说明:
- 直观价格涨跌比例
- 多期简单收益**不能直接累加**
- 常用于直观收益展示、普通行情计算

### 对数收益率（Log Return）:

$$
r_t = \ln\left(\dfrac{P_t}{P_{t-1}}\right)
$$

- 说明:
- 也叫**连续复利收益率**
- 多期对数收益**可直接相加**，量化、时间序列建模、金融建模首选
- 满足正态分布假设，适合做回归、策略回测

### 两者互推关系:
$$
r_t = \ln(1+R_t)
$$

$$
R_t = e^{r_t} - 1
$$

## 改变时间序列的时间频率：

- 处理金融时间序列时经常需要改变数据的频率（周期），比如我们的算法需要用到每日级别频率，但我们的数据是每小时级别频率，这时候就要用到这种方法了；

- 改变时间序列频率的方法一般分为以下两种：

- **1.将对数收益乘以或除以时间周期数**

- **2.将以实现波动率乘以或除以时间周期数的平方根**

- 已实现波动率RV的计算公式如下：

### 符号定义
- $N$：一日内高频收益率采样个数
- $r_{t,i}$：第 $t$日第 $i$个**对数收益率**
- $RV_t$：第 $t$ 日**已实现波动率**

### 核心公式（标准已实现方差 → 已实现波动率）
- 1. 已实现方差 Realized Variance
$$
RV_{var,t} = \sum_{i=1}^{N} r_{t,i}^2
$$

- 2. 已实现波动率 Realized Volatility（RV）
$$
RV_t = \sqrt{\,\sum_{i=1}^{N} r_{t,i}^2\,}
$$

### 年化已实现波动率
若日内是**日度频率**采样，一年按252个交易日：
$$
RV_{annual,t} = \sqrt{252} \cdot \sqrt{\,\sum_{i=1}^{N} r_{t,i}^2\,}
$$

### 补充说明
1. 输入必须用**高频对数收益率** $r_{t,i}=\ln(P_{t,i}/P_{t,i-1})$；
2. 原理：用日内高频收益平方和替代瞬时积分方差，无需参数模型；
3. 量化、波动率建模、GARCH对比、期权隐含波动率对标都用RV。

## 代码复现：

- 我使用的是比特币小时级别收益率数据，并考虑将其转化为日线级别收益率数据；

```python
import pandas as pd
import numpy as np

import matplotlib.pyplot as plt

# 设置绘图风格
plt.rcParams['font.sans-serif'] = ['Arial Unicode MS']  # 解决中文显示（Mac用'Arial Unicode MS'）
plt.rcParams['axes.unicode_minus'] = False

# 定义计算已实现波动率的函数
def realized_volatility(x):
    return np.sqrt(np.sum(x**2))
#计算每小时已实现波动率，并将结果命名为RV
df_RV = df["log_rtn"].resample("1D").apply(realized_volatility).rename("RV")
#年化该值：
df_RV = df_RV.to_frame()
df_RV["RV_yearly"] = df_RV["RV"] * np.sqrt(24*365)
#绘制结果：
fig,ax = plt.subplots(2,1)
ax[0].plot(df_RV["RV"])
ax[0].set_title("btc's log return")
ax[1].plot(df_RV["RV_yearly"])
ax[1].set_title("btc's yearly realized volatility")
plt.tight_layout()
plt.show()

plt.figure(figsize=(12, 5))
plt.plot(df_RV["RV"], label="日已实现波动率 RV", color="#1f77b4")
plt.plot(df_RV["RV_yearly"], label="年化已实现波动率", color="#ff7f0e")
plt.legend()
plt.title("RV 与 年化 RV 对比")
plt.show()
```
