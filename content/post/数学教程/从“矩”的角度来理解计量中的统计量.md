- **经过我的学习和研究发现，传统的多因子模型实际上就是计量经济学的延伸与实际拓展运用，所以搞懂计量经济学中必须掌握的各种统计量对研究量化模型是至关重要的，所以我写了这篇文章，目的是带大家巩固常用的计量统计量**
- 本篇文章中我们从一个核心思想出发：**“几乎所有的经典统计量，都可以看作是某种“矩”（moment），或是矩的变换、亦或是条件矩、再或是矩的缺失。”**  
那么只要理解了矩，就等于拿到了理解整个计量经济学和量化多因子模型的“母钥匙”。

- 接下来我会尝试先讲清楚什么是矩，然后用三组有实际意义的数据，把每一个统计量都从矩的视角“拆开来看”。

## 一、先弄明白：什么是“矩”？

在概率论和统计学中，假设我们有一组或多组数据，那么**矩**就是分别描述它们分布形状的一组特征数。

- **原点矩（raw moment）**：  
  $\mu'_k = E[X^k]$  
  即随机变量 k 次幂的期望，这里既可以指离散型随机变量也可以指连续型随机变量。  
  **1阶原点矩**就是均值。除此之外还有2阶原点矩：$E(X^2)$、3阶原点矩：$E(X^3)$、4阶原点矩：$E(X^4)$

- **中心矩（central moment）**：  
  $\mu_k = E[(X - E[X])^k]$  
  即变量减去均值后的 k 次幂的期望，同理，这里既可以指离散型随机变量也可以指连续型随机变量。  
  **2阶中心矩**就是方差。3 阶中心矩是偏度来源、4 阶中心矩是峰度来源

- **标准化矩（standardized moment）**：  
  中心矩除以标准差的 k 次方：  
  $\tilde{\mu}_k = \frac{\mu_k}{\sigma^k}$ 
  3阶标准化矩是偏度，4阶标准化矩是峰度。

- **样本矩 vs 总体矩**:
现实中我们只有样本数据，不知道总体，所以用样本矩近似总体矩，所有日常算的均值、方差都是样本矩估计量。

所有基于“期望”的统计量，本质上都是各种矩，或是矩的组合。  
而中位数、众数虽然不是矩，但它们是分布的位置参数，可以用伽尔顿-皮尔逊的“矩法”与矩建立联系，或是作为比矩更“稳健”的位置度量存在。

## 二、准备三组有实际意义的数据

为了让每一个统计量的意义鲜活起来，我构造了三个班的期末考试成绩，且每个班只有5名学生。

- **A班（均衡高分段）**：85, 87, 90, 92, 96  
- **B班（中等但有极端低分）**：55, 78, 85, 90, 92  
- **C班（两极分化）**：40, 55, 80, 95, 100  

这三个班的真实含义：
- A班是所谓的“重点班”，成绩集中且偏高。
- B班有一个明显掉队的学生（55分），但其他人都比较正常。
- C班严重的两极分化，有人不及格，但有人却近乎满分。

## 三、位置统计量：众数、中位数、均值

### 3.1 均值（Mean）—— 一阶原点矩

均值就是我们最熟悉的算数平均，它的矩定义是：
- $$\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i = \text{样本一阶原点矩} \ \hat{\mu}'_1$$
完全就是矩的样本实现。

计算结果：
- A班：(85+87+90+92+96)/5 = **90.0**
- B班：(55+78+85+90+92)/5 = **80.0**
- C班：(40+55+80+95+100)/5 = **74.0**

从一阶矩的角度，A班最好，C班最差。  
但是只看均值来评价三个班级是不合理的，我们就错过了分布的形状——B班均值80看起来不差，但它有一个55分拖后腿；C班均值74，但不能看出它内部两极分化多严重。所以说均值受到极端值的影响是巨大的。

**矩的局限性就在这里**：一阶矩只告诉你“中心位置”，但并不告诉你数据是怎么围绕这个中心分布的。

---

### 3.2 中位数（Median）—— 50%分位数，位置的“稳健矩替代品”

中位数不是矩，因为它不能写成一个幂的期望。  
它是把数据排序后中间的值，等价于分布的 **0.5 分位数**。  
如果我们把分布看作一个概率密度，中位数是满足 $\int_{-\infty}^m f(x)dx = 0.5$ 的点。

- A班排序：85, 87, 90, 92, 96 → 中位数 **90**
- B班排序：55, 78, 85, 90, 92 → 中位数 **85**
- C班排序：40, 55, 80, 95, 100 → 中位数 **80**

对比均值和位数：
- A班均值90，中位数90 → 对称分布
- B班均值80，中位数85 → 均值被低分拉低，中位数更“稳健”
- C班均值74，中位数80 → 均值被极端低分拉得更低

**从矩的角度去理解**：均值是我们接下来要讲的二阶中心距的最小化平方误差的中心；中位数是最小化绝对误差（一阶绝对矩）的中心。  

---

### 3.3 众数（Mode）—— 最高概率密度点，跟矩无关但可以“用矩法估计”

众数是出现次数最多的值。对连续分布是概率密度的最大值。它完全不用任何矩的概念来定义，因为它只关心“最可能的值”。

这里数据太少，众数可能不明显或没有（若都不重复就无众数）。  
在三组里，所有分数都是唯一的，但如果我们组距划分，A班85-90最密集，众数大约在89附近；B班85-90密集，众数也接近85-90；C班可能出现双众数（40-55 和 95-100）的迹象。

在皮尔逊经验公式里，众数可以用矩来近似：  
众数 ≈ 3×中位数 − 2×均值（适用于单峰、中等偏态分布）。  
这也说明，虽然没有直接的“众数矩”，但分布的前两阶矩包含了一部分众数信息。

## 四、离散程度统计量：方差、标准差、标准误

### 4.1 方差（Variance）—— 二阶中心矩

- $$\text{Var}(X) = E[(X - \mu)^2] = \mu_2$$
这是最核心的离散度量。它是去中心化、平方以后的期望，所以如果数据离均值远，平方惩罚会很大。

计算（用分母 n ，但理解时可以用无偏 n-1 ，本质一样是矩）：
- A班均值90：  
  离差平方：(85-90)²=25, (87-90)²=9, (90-90)²=0, (92-90)²=4, (96-90)²=36  
  方差 = (25+9+0+4+36)/5 = 74/5 = **14.8**
- B班均值80：  
  离差平方：(55-80)²=625, (78-80)²=4, (85-80)²=25, (90-80)²=100, (92-80)²=144  
  方差 = (625+4+25+100+144)/5 = 898/5 = **179.6**
- C班均值74：  
  离差平方：(40-74)²=1156, (55-74)²=361, (80-74)²=36, (95-74)²=441, (100-74)²=676  
  方差 = (1156+361+36+441+676)/5 = 2670/5 = **534.0**

**矩视角的解读**：  
- 二阶中心矩将偏离均值的距离平方化。这导致 B、C班的方差远远大于A班。  
B班因为仅有一个极端低分（55），其方差就达到了179.6，而C班两极严重分化，方差飙到534。  
这也是为什么金融里波动率（标准差）会因一两次极端收益而剧烈上升的原因——二阶矩对极端值极度敏感。

### 4.2 标准差（Standard Deviation）—— 方差的平方根，尺度和均值同量纲

- $$\sigma = \sqrt{\text{Var}(X)} = \sqrt{\mu_2}$$
- A：√14.8 ≈ **3.85**
- B：√179.6 ≈ **13.40**
- C：√534.0 ≈ **23.11**

标准差可以看作“典型的偏离程度”。它的单位跟原始分数一样(因为方差的平方改变了单位，二根号去平方后单位又回归到一开始的模样来)，这是它比方差更直观的原因。

### 4.3 标准误（Standard Error）—— 估计量（常为均值）的分布的标准差

这是很多人混淆的概念。  
方差和标准差描述**数据本身**的分散程度；而标准误描述**样本统计量例如样本均值**的分散程度。

样本均值的方差：$\text{Var}(\bar{X}) = \frac{\sigma^2}{n}$  
样本均值的标准误：$SE(\bar{X}) = \frac{\sigma}{\sqrt{n}}$

对A班：SE = 3.85 / √5 ≈ **1.72**  
B班：13.40 / √5 ≈ **5.99**  
C班：23.11 / √5 ≈ **10.34**

**从矩的角度看**：  
标准误是“均值这个随机变量”的二阶中心矩的平方根。  
如果我们重复抽取样本，样本均值会形成一个分布，那个分布的标准差就是标准误。

## 五、回归与线性关系中的矩：残差、协方差、相关、同方差/异方差

现在我们进入计量经济的核心地带。

假设我们想用B班成绩去“解释”C班成绩（或者反过来），或者我们研究两组成绩之间的关系，就引入随机向量。矩向多元扩展，就出现了**协方差**。

### 5.1 协方差（Covariance）—— 二阶混合中心矩

定义：
- $$\text{Cov}(X,Y) = E[(X - \mu_X)(Y - \mu_Y)]$$
这是混合矩：一个变量的离差乘以另一个变量的离差的期望。

为了有实际意义，假设A、B、C这三组数据分别是同一个学生三次不同考试的成绩，身份一一对应（学生1~5）：
- 学生1：A 85, B 55, C 40
- 学生2：A 87, B 78, C 55
- 学生3：A 90, B 85, C 80
- 学生4：A 92, B 90, C 95
- 学生5：A 96, B 92, C 100

计算 A 和 B 的协方差：
- 均值：A=90, B=80
- 离差积：
- (85-90)(55-80)=(-5)×(-25)=125  
- (87-90)(78-80)=(-3)×(-2)=6  
- (90-90)(85-80)=0×5=0  
- (92-90)(90-80)=2×10=20  
- (96-90)(92-80)=6×12=72  
- 协方差 = (125+6+0+20+72)/5 = 223/5 = **44.6**

A 和 C 的协方差：
- C均值=74  
  离差积：
- (-5)(40-74)=(-5)×(-34)=170  
- (-3)(55-74)=(-3)×(-19)=57  
- (0)(80-74)=0  
- (2)(95-74)=2×21=42  
- (6)(100-74)=6×26=156  
- 协方差 = (170+57+0+42+156)/5 = 425/5 = **85.0**

**矩的解读**：  
协方差的数值符号表示两个变量同向还是反向变化，大小受各自方差影响，不太好直接比较，且协方差衡量的是同向变动或反向变动的幅度大小，并不能直接反应二者之间的相关性，相关系数亦是如此。  
A和C的协方差大于A和B，是因为C与A的离差“幅度”更大（C的方差更大），不一定代表线性关系更强。

### 5.2 相关系数（Correlation coefficient）—— 标准化后的协方差

- $$\rho_{X,Y} = \frac{\text{Cov}(X,Y)}{\sigma_X \sigma_Y}$$
这本质上是将两个变量都标准化（变为均值0、方差1）之后的协方差，也就是说，它是**标准化变量的二阶混合矩**。

- σ_A=3.85, σ_B=13.40, σ_C=23.11  
- ρ_AB = 44.6 / (3.85×13.40) ≈ 44.6 / 51.59 ≈ **0.865**
- ρ_AC = 85.0 / (3.85×23.11) ≈ 85.0 / 88.97 ≈ **0.955**

解读：相关系数将协方差的量纲去掉，变成-1到1之间的纯数。  
A和C的线性关联比A和B更强，尽管C的分数范围广得多。

**矩视角**：从协方差（混合二阶中心矩）到相关系数，只是一次矩的标准化（除以标准差）。

---

### 5.3 残差（Residual）—— 条件矩移除线性成分后的剩余部分

建立一元回归：  
$$C_i = \beta_0 + \beta_1 A_i + \varepsilon_i$$

残差 $e_i = C_i - \hat{C}_i$，是实际值与拟合值的差。  
从矩的角度理解，OLS回归本质上是在用A的矩信息去拟合C的条件期望（一阶条件矩），残差则是这个条件一阶矩被剥离后剩下的部分。

OLS估计的最小化目标是残差平方和，这就是在最小化残差的二阶矩（方差）。

如果用A和C数据做回归：
- β₁ = Cov(A,C)/Var(A) = 85.0 / 14.8 ≈ 5.743
- β₀ = mean(C) - β₁×mean(A) = 74 - 5.743×90 ≈ 74 - 516.87 = -442.87

拟合值：
- 学生1：-442.87 + 5.743×85 ≈ 45.3, 实际40 → 残差 ≈ -5.3
- 学生2：-442.87 + 5.743×87 ≈ 56.8, 实际55 → 残差 ≈ -1.8
- 学生3：-442.87 + 5.743×90 ≈ 74.0, 实际80 → 残差 ≈ +6.0
- 学生4：-442.87 + 5.743×92 ≈ 85.5, 实际95 → 残差 ≈ +9.5
- 学生5：-442.87 + 5.743×96 ≈ 108.4, 实际100 → 残差 ≈ -8.4

残差的均值应为0（这是一阶条件矩约束）。  
残差的方差是所有残差的二阶中心矩，代表模型解释不了的部分。

### 5.4 同方差（Homoskedasticity）与异方差（Heteroskedasticity）—— 条件二阶矩的恒定性与变化性

这是经典线性回归假设之一：
- $$\text{Var}(\varepsilon_i | X_i) = \sigma^2 \quad \text{常数}$$
这就是同方差：无论X取什么值，它与误差项的条件二阶矩（方差）都相同。

如果这个条件二阶矩随X变化，例如X越大，误差方差越大（扇形散点图），就叫**异方差**。

在我们的小例子中，由于数据太少，5个点的残差方差很难判断是否恒定，但我们可以想象一个大样本：当A班分数从85到96增加时，如果预测C班的误差幅度明显在变大，这就表明条件二阶矩不是常数，即异方差。

**计量经济学里为什么重视它？**  
因为标准误（系数估计量的标准误）的估计依赖于误差方差结构。如果异方差被忽略，系数的标准误估计会偏，导致t检验失效。这也正是“稳健标准误”（White标准误）要做的事——重新估计系数的协方差矩阵，允许误差条件二阶矩随X变化。

## 六、高阶矩：偏度与峰度

均值（一阶）和方差（二阶）只刻画了位置和离散度。要描述分布的“形状”，必须用更高阶的矩。

### 6.1 偏度（Skewness）—— 三阶标准化矩

- $$\text{Skewness} = E\left[ \left(\frac{X - \mu}{\sigma}\right)^3 \right] = \frac{\mu_3}{\sigma^3}$$
它衡量不对称程度：
- 由于三次方放大了波动，且保留了符号正负，所以可以描述数据了分布趋势
- 正偏（右偏）：右尾长，均值 > 中位数（多数金融收益率正偏很小但频现极端正值对数正态）
- 负偏（左偏）：左尾长，均值 < 中位数

计算A班（均值90, σ≈3.85）：
标准化离差：(-5/3.85)³ + (-3/3.85)³ + 0 + (2/3.85)³ + (6/3.85)³  
粗略算：
- z1 = -1.299, z1³ ≈ -2.19
- z2 = -0.779, z2³ ≈ -0.47
- z3 = 0
- z4 = 0.519, z4³ ≈ 0.14
- z5 = 1.558, z5³ ≈ 3.78  
Sum ≈ 1.26, 除以5 ≈ **0.252** → 轻微右偏（因为96高分拉远）。

B班均值80, σ≈13.40：
z1=(55-80)/13.4≈ -1.866 → ³ ≈ -6.49  
z2=(78-80)/13.4≈ -0.149 → ³ ≈ -0.003  
z3=0.373 → ³≈0.052  
z4=0.746 → ³≈0.415  
z5=0.896 → ³≈0.719  
Sum ≈ -5.307, /5 ≈ **-1.06** → 明显左偏（低分拉大左尾）。

C班均值74, σ≈23.11：
z1=(40-74)/23.11≈ -1.471 → ³≈ -3.18  
z2=-0.822 → ³≈ -0.56  
z3=0.260 → ³≈ 0.017  
z4=0.909 → ³≈ 0.75  
z5=1.125 → ³≈ 1.42  
Sum ≈ -1.55, /5 ≈ **-0.31** → 轻微左偏，因为低分两个，但高分也很高，偏度不大。

**矩的含义**：三阶矩对离群值的方向极为敏感，因为它保留了符号（奇次幂），并且放大了距离。它是所有非对称信息的“集中营”。

### 6.2 峰度（Kurtosis）—— 四阶标准化矩


- $$\text{Kurtosis} = E\left[ \left(\frac{X - \mu}{\sigma}\right)^4 \right] = \frac{\mu_4}{\sigma^4}$$
正态分布的峰度是3，所以常有过量峰度 = 峰度 - 3。峰度高意味着尾部和峰值同时加重（因为标准化让方差恒定，四阶矩大说明更极端值更多，同时中心也更尖）。

计算A班近似：
z⁴：1.299⁴≈2.85, 0.779⁴≈0.37, 0, 0.519⁴≈0.07, 1.558⁴≈5.89  
Sum≈9.18, /5≈1.836 → **远小于3**，说明分布很薄尾，没有极端值（有限5个点均匀）。

B班：
z1⁴: (-1.866)⁴≈12.13  
z2: (-0.149)⁴≈0.0005  
z3: 0.373⁴≈0.019  
z4: 0.746⁴≈0.31  
z5: 0.896⁴≈0.64  
Sum≈13.1, /5≈2.62 → 略低于3，但靠近。

C班：
z1:1.471⁴≈4.68, z2:0.822⁴≈0.46, z3:0.26⁴≈0.005, z4:0.909⁴≈0.68, z5:1.125⁴≈1.60  
Sum≈7.43, /5≈1.49 → 远低于3。  
但是这里可能因为样本小失真，真实数据集若有两极分化且中间单薄，可能峰度会低（均匀状），若两极加中心多则高。本质是分布的尾重程度。

**金融意义**：资产收益率的峰度通常远大于3（尖峰厚尾），意味着极端事件（黑天鹅）概率远高于正态预期。量化多因子模型中，因子收益的峰度高意味着必须对极端风险做专门管理。

## 七、标准化与归一化 —— 分布矩的变换操作

### 7.1 标准化（Standardization，Z-score）

- $$Z = \frac{X - \mu}{\sigma}$$
变换后，**一阶中心矩=0，二阶中心矩=1**。所有的尺度信息被剥离，只保留分布形状（高阶矩偏度峰度不变）。  
在多因子模型中，这步几乎是必须的，为了让不同量纲的因子（如市值、动量）可以进行横向比较和组合。

### 7.2 归一化（Normalization，Min-Max scaling 等）

- $$X_{\text{norm}} = \frac{X - X_{\min}}{X_{\max} - X_{\min}}$$
这不是基于矩，而是基于极值（分位数）。它使数据被限制在[0,1]区间。

**矩的对比**：标准化用到了均值（一阶矩）和标准差（二阶矩开方），而归一化完全依靠顺序统计量（最大最小值）。标准化对离群值敏感，归一化则把所有特征放在同一绝对范围。

## 八、用矩串起整个故事

想象数据生成过程是一层一层的：

1. **一阶条件矩**（均值、回归预测值）给出位置；
2. **二阶矩**（方差、协方差）给出离散和关联；
3. **条件二阶矩**的恒定性决定同方差/异方差，直接影响到标准误的质量；
4. **三阶标准化矩**（偏度）描述不对称风险；
5. **四阶标准化矩**（峰度）描述极端风险；
6. **标准化**把不同变量拉到同一尺度，再构高阶矩才有可比性；
7. 中位数和众数虽然不直接是矩，但它们是因为矩对极端值过于敏感而被引入的“稳健替代品”。

在量化多因子模型中，因子收益率截面上的**均值**代表因子溢价（一阶矩），**方差-协方差矩阵**用来估计风险和组合优化（二阶矩），因子的**偏度**和**峰度**反映极端收益分布（高阶矩），残差的同方差性/异方差性决定模型推断是否有效。这一切，本质上全都是对数据不同阶次、不同条件下的矩的结构分析。
