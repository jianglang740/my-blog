## 项目背景

加密市场没有统一的行情与交易接口，每个交易所的 API 在鉴权、限频、订单结构上都不一样，策略代码很容易被交易所细节污染。CCXT 提供了统一抽象，这个项目基于它搭一套**策略与交易所解耦**的工程骨架。

## 技术栈

- **语言**：Python
- **交易所接口**：CCXT
- **数据存储**：MySQL、PyMySQL
- **数据处理**：pandas

## 我的工作

- **统一接口层**：封装 CCXT，抹平不同交易所在下单、查持仓、订阅行情上的差异
- **行情采集与落库**：设计 K 线表结构，处理增量写入与重复数据去重
- **工程结构**：按"数据 / 策略 / 交易 / 配置"拆分多文件夹结构，策略只依赖内部接口，不直接接触交易所 SDK
- **配置管理**：API 密钥与策略参数外置，避免硬编码进代码
