## 第一部分：先建立资产定价理论的整体认知

在进入任何模型之前，先把三个最基本的概念钉牢：实际收益率、预期收益率和风险溢价。这一部分不急着写公式推导，而是回答一个更前置的问题——我们到底在解释什么，以及系统性风险为什么值得被补偿。

### 1.1 我们究竟在研究什么问题？

假设我在美国股票市场选择了三只股票：

| 股票 | 公司特征 | 年化收益率（假设） |
|---|---|---:|
| A | 大型成熟企业 | 8% |
| B | 小型成长企业 | 15% |
| C | 小型价值企业 | 18% |

这里存在一个值得研究的问题：

为什么不同股票的长期平均收益率存在差异？

可能的解释有很多：

1. 股票承担的市场系统性风险不同。
2. 小市值股票承担了额外风险。
3. 价值型股票承担了额外风险。
4. 某些股票具有更强的动量特征。
5. 不同股票对宏观经济、流动性等风险因素的敏感程度不同。

这些解释实际上都在尝试回答一个核心问题：

**资产的预期收益率究竟由什么决定？**

资产定价理论（Asset Pricing Theory）就是围绕这个问题发展起来的。

在学习过程中，需要区分三个概念。

#### 1.1.1 实际收益率（Realized Return）

实际收益率是已经发生的收益率。

例如：

某只股票在 1 月份上涨了 5%，那么 5% 就是它在该月份的实际收益率。

记作：

\[ R_{i,t} \]

其中：

- \(i\)：资产编号。
- \(t\)：时间。
- \(R_{i,t}\)：资产 \(i\) 在时间 \(t\) 的实际收益率。

#### 1.1.2 预期收益率（Expected Return）

预期收益率是站在当前时点，对未来收益率的概率期望。

\[ E(R_i) \]

它不是对未来收益的准确预测，而是给定信息集和模型假设下的数学期望。

注意：

历史平均收益率只是预期收益率的一个估计量，并不等于真正的预期收益率。

#### 1.1.3 风险溢价（Risk Premium）

风险溢价是投资者为了承担风险而要求获得的额外预期收益。

如果无风险利率为：

\[ R_f=3\% \]

某资产的预期收益率为：

\[ E(R_i)=10\% \]

那么它的预期风险溢价就是：

\[ E(R_i)-R_f=7\% \]

资产定价理论研究的重点，并不是简单地解释哪只股票涨得更多，而是解释：

**为什么某些资产需要提供更高的预期风险溢价，市场才愿意持有它们？**

### 1.2 理解系统性风险与非系统性风险

这是理解 CAPM 的前置知识。

假设我持有一家航空公司的股票。

这只股票可能受到两类风险影响：

**第一类：系统性风险（Systematic Risk）**

- 全球经济衰退。
- 利率上升。
- 整体股票市场下跌。
- 金融危机。
- 大规模流动性收缩。

这些因素会同时影响大量股票。

**第二类：非系统性风险（Idiosyncratic Risk）**

- 公司飞机发生事故。
- 管理层出现丑闻。
- 某项业务失败。
- 公司自身经营出现问题。

这些因素主要影响个别企业。

投资者可以通过持有大量不同股票，分散相当一部分非系统性风险。

但即使持有 1000 只股票，也无法完全避免全球金融危机带来的系统性风险。

因此，经典资产定价理论的一个重要思想是：

> 在充分分散投资的条件下，投资者主要需要为无法通过分散投资消除的系统性风险获得补偿。

这就引出了 CAPM。

### 1.3 四个理论和方法之间的关系

我可以先把整个知识体系概括为：

| 理论或方法 | 核心问题 | 核心思想 |
|---|---|---|
| CAPM | 市场风险如何决定收益率？ | 一个市场风险因子 |
| APT | 多种系统性风险如何决定收益率？ | 无套利与多因子定价 |
| Fama-French | 哪些因子能够解释股票收益差异？ | 将规模、价值等因子加入市场因子 |
| Fama-MacBeth | 如何检验这些因子是否具有定价能力？ | 两阶段回归估计风险溢价 |

需要特别注意：

Fama-MacBeth 并不是 CAPM 或 APT 的下一代定价理论，而是一种实证检验方法。

它可以用来检验 CAPM，也可以用来检验 APT 类型的多因子模型和 Fama-French 模型。

整个过程可以理解为：

\[ \boxed{ \text{经济理论} \rightarrow \text{因子模型} \rightarrow \text{因子暴露} \rightarrow \text{风险溢价估计} \rightarrow \text{模型检验} } \]

## 第二部分：CAPM——从单一市场风险因子理解资产定价

有了风险溢价的概念，CAPM 给出了最简洁的答案：只用一个市场 Beta 就能解释预期收益。这一部分从 Markowitz 均值方差优化出发，经资本市场线推导出 Beta，再回到 OLS 与时间序列回归，最后讨论 CAPM 在实证中留下的 Alpha 和局限。

### 2.1 CAPM 是什么？

CAPM，全称 Capital Asset Pricing Model，即资本资产定价模型。

其经典理论由 William Sharpe、John Lintner 等人的研究发展而来。

Sharpe 于 1964 年发表了经典论文：

*Capital Asset Prices: A Theory of Market Equilibrium under Conditions of Risk.*

CAPM 最重要的贡献，是将现代投资组合理论中的风险与收益关系，进一步推导为单个资产的均衡预期收益率关系。

它提出：

**资产的预期收益率与其承担的市场系统性风险呈线性关系。**

CAPM 的基本公式：

\[ E(R_i)=R_f+\beta_i[E(R_m)-R_f] \]

其中：

| 符号 | 含义 |
|---|---|
| \(E(R_i)\) | 资产 \(i\) 的预期收益率 |
| \(R_f\) | 无风险利率 |
| \(E(R_m)\) | 市场组合的预期收益率 |
| \(E(R_m)-R_f\) | 市场风险溢价 |
| \(\beta_i\) | 资产相对于市场组合的系统性风险暴露 |

我们逐步推导这个公式，而不是直接记住它。

### 2.2 CAPM 的理论基础：Markowitz 均值方差理论

CAPM 建立在现代投资组合理论（Modern Portfolio Theory）的基础之上。

Markowitz 的核心思想是：

投资者在选择投资组合时，需要同时考虑：

- 预期收益率（Expected Return）。
- 收益率方差（Variance）。
- 不同资产之间的协方差（Covariance）。

假设一个投资组合包含 \(N\) 只股票。

股票权重组成向量：

\[ \mathbf{w}= \begin{bmatrix} w_1\\ w_2\\ \vdots\\ w_N \end{bmatrix} \]

各资产的预期收益率组成：

\[ \boldsymbol{\mu}= \begin{bmatrix} \mu_1\\ \mu_2\\ \vdots\\ \mu_N \end{bmatrix} \]

收益率协方差矩阵：

\[ \boldsymbol{\Sigma} \]

那么组合预期收益率为：

\[ E(R_p)=\mathbf{w}^{T}\boldsymbol{\mu} \]

组合收益率方差为：

\[ \sigma_p^2= \mathbf{w}^{T} \boldsymbol{\Sigma} \mathbf{w} \]

这两个公式非常重要。

它们分别告诉我们：

1. 组合预期收益率是各资产预期收益率的加权平均。
2. 组合风险不仅取决于单个资产的风险，还取决于资产之间的协方差。

例如：

两只股票各自的波动率都很高，但如果它们的收益率相关性很低，那么将它们放在同一个组合中，可能降低组合整体风险。

这就是分散化的数学基础。

#### 均值方差优化

假设投资者希望在给定目标收益率的条件下，使组合风险最小。

可以写成：

\[ \min_{\mathbf{w}} \quad \mathbf{w}^{T}\Sigma\mathbf{w} \]

约束条件：

\[ \begin{cases} \mathbf{w}^{T}\boldsymbol{\mu}=\mu_p\\ \mathbf{w}^{T}\mathbf{1}=1 \end{cases} \]

不同目标收益率对应不同的最优投资组合。

把这些最优组合连接起来，就可以得到有效前沿（Efficient Frontier）。

有效前沿上的组合具有这样的性质：

不存在另一个组合，能够在风险更低的同时提供不低于它的预期收益率。

### 2.3 加入无风险资产：资本市场线

现在引入无风险资产。

例如：

- 美国短期国债可以作为无风险利率的近似代理。
- 市场组合可以用广泛分散的股票市场组合表示。

投资者可以将资金配置在：

1. 无风险资产。
2. 有效前沿上的某个风险资产组合。

当允许投资者按照无风险利率进行借贷时，经过无风险利率点并与风险资产有效前沿相切的直线，就是资本市场线（Capital Market Line，CML）。

在 CAPM 的理想化假设下，所有投资者面对相同的投资机会和预期收益率分布，因此会持有相同的风险资产切点组合。

在市场均衡中，这个组合对应市场组合。

因此，市场组合是有效的。

这里得到一个重要结论：

市场组合中的所有资产，其预期收益率与风险之间必须满足某种均衡关系。

但需要注意：

资本市场线描述的是有效投资组合的预期收益率与总波动风险之间的关系。

而 CAPM 最终要解释的是单个资产的预期收益率与系统性风险之间的关系。

两者不能混为一谈。

### 2.4 从组合风险推导单个资产的 Beta

现在进入 CAPM 最关键的推导。

假设市场组合为 \(M\)，我们考虑一只股票 \(i\)。

在市场组合中，股票 \(i\) 的权重为 \(w_i\)。

市场组合收益率：

\[ R_M=\sum_{j=1}^{N}w_jR_j \]

我们关注股票 \(i\) 对市场组合风险的贡献。

市场组合方差为：

\[ \sigma_M^2= Var(R_M) \]

展开协方差：

\[ Cov(R_i,R_M) = Cov\left(R_i,\sum_{j=1}^{N}w_jR_j\right) \]

利用协方差的线性性质：

\[ Cov(R_i,R_M) = \sum_{j=1}^{N}w_jCov(R_i,R_j) \]

其中，股票 \(i\) 与市场组合的协方差反映了股票对市场组合波动的共同变化程度。

CAPM 将这种风险暴露标准化为 Beta：

\[ \boxed{ \beta_i= \frac{Cov(R_i,R_M)} {Var(R_M)} } \]

这就是 Beta 的定义。

#### Beta 应该如何理解？

假设：

\[ \beta_i=1.5 \]

意味着在基于历史关系估计的线性模型中，当市场超额收益率增加 1 个百分点时，该资产的预期超额收益率平均增加约 1.5 个百分点。

它不意味着：

股票一定比市场上涨更多，也不意味着每一天都遵循这个比例。

再看几个典型情况：

| Beta | 解释 |
|---:|---|
| 0 | 与市场不存在相应的线性风险暴露 |
| 0.5 | 市场敏感程度相对较低 |
| 1 | 与市场具有相同量级的系统性风险暴露 |
| 1.5 | 对市场变动更加敏感 |
| -0.5 | 与市场呈负向线性风险暴露 |

这里要特别注意：

Beta 衡量的是协方差意义上的系统性风险，而不是总波动率。

一只股票可以具有很高的波动率，但如果其波动主要来自公司自身事件，那么它的 Beta 仍然可能不高。

### 2.5 从 Beta 推导 CAPM 的预期收益率公式

CAPM 的关键在于：

市场组合既然是均衡有效组合，那么市场组合中每个资产的预期收益率，都必须与它对市场组合风险的贡献相匹配。

从均衡条件可以得到：

\[ E(R_i)-R_f = \frac{Cov(R_i,R_M)} {Var(R_M)} [E(R_M)-R_f] \]

代入 Beta 的定义：

\[ \boxed{ E(R_i)-R_f= \beta_i[E(R_M)-R_f] } \]

整理后：

\[ \boxed{ E(R_i)=R_f+\beta_i[E(R_M)-R_f] } \]

这就是 CAPM。

它告诉我们：

一只股票的预期收益率由两个部分组成：

1. 无风险收益率。
2. 与市场风险暴露相对应的风险补偿。

#### 一个具体的数值例子

假设：

- 无风险利率：3%。
- 市场预期收益率：9%。
- 股票 A 的 Beta：1.5。
- 股票 B 的 Beta：0.5。

股票 A 的预期收益率：

\[ E(R_A)=3\%+1.5(9\%-3\%) \]

\[ =12\% \]

股票 B 的预期收益率：

\[ E(R_B)=3\%+0.5(9\%-3\%) \]

\[ =6\% \]

CAPM 认为，股票 A 因为承担了更多市场风险，所以应该获得更高的预期收益率。

这并不意味着股票 A 一定会实现 12% 的收益率，而是理论上的均衡预期收益率。

### 2.6 CAPM 的实证形式：时间序列回归

前面的 CAPM 是理论形式。

但在实际研究中，我们拿到的是历史收益率数据，而不是真正的未来预期收益率。

因此需要建立一个可以估计的回归模型。

CAPM 的时间序列回归形式为：

\[ \boxed{ R_{i,t}-R_{f,t} = \alpha_i+ \beta_i(R_{m,t}-R_{f,t}) +\epsilon_{i,t} } \]

其中：

- \(R_{i,t}-R_{f,t}\)：股票超额收益率。
- \(R_{m,t}-R_{f,t}\)：市场超额收益率。
- \(\alpha_i\)：截距项。
- \(\beta_i\)：市场风险暴露。
- \(\epsilon_{i,t}\)：残差。

这是一个普通的线性回归模型：

\[ y=\alpha+\beta x+\epsilon \]

其中：

\[ y_t=R_{i,t}-R_{f,t} \]

\[ x_t=R_{m,t}-R_{f,t} \]

使用 OLS（普通最小二乘法）即可估计 Beta 和 Alpha。

#### Alpha 是什么？

Alpha 是 CAPM 无法由市场风险解释的平均超额收益部分。

例如：

回归结果为：

\[ R_i-R_f= 0.002+1.2(R_m-R_f)+\epsilon \]

那么：

- Beta = 1.2。
- Alpha = 0.002。

如果数据以月收益率的小数形式表示，那么 Alpha 对应月度 0.2%。

如果 Alpha 显著大于 0，意味着该资产的平均收益率高于 CAPM 根据市场风险暴露所预测的收益率。

这可能意味着：

1. CAPM 遗漏了其他系统性风险因素。
2. 存在错误定价。
3. 模型设定存在问题。
4. 样本中存在偶然性或估计误差。

因此，不能直接将显著 Alpha 理解为投资者一定可以获得的稳定超额收益。

### 2.7 OLS 为什么可以用来估计 Beta？

OLS 的目标是让所有观测点到回归直线的残差平方和最小。

假设：

\[ y_t=\alpha+\beta x_t+\epsilon_t \]

OLS 求解：

\[ \min_{\alpha,\beta} \sum_{t=1}^{T} (y_t-\alpha-\beta x_t)^2 \]

对 \(\alpha\) 和 \(\beta\) 分别求偏导并令其为零。

最终得到：

\[ \hat{\beta} = \frac{ \sum_{t=1}^{T}(x_t-\bar{x})(y_t-\bar{y}) }{ \sum_{t=1}^{T}(x_t-\bar{x})^2 } \]

也就是：

\[ \boxed{ \hat{\beta}= \frac{Cov(x,y)}{Var(x)} } \]

而：

\[ \hat{\alpha}=\bar{y}-\hat{\beta}\bar{x} \]

所以我们在 CAPM 回归中得到的 Beta，本质上就是股票超额收益率对市场超额收益率的线性敏感度。

> **可视化提示**：最小二乘回归的几何含义可以这样理解——在所有解释变量张成的空间里，OLS 寻找的是让残差向量长度最短的那个投影点；一元回归中，拟合直线的斜率就是 \(y\) 在 \(x\) 方向上投影的斜率。若使用支持交互式图表的工具，可以拖动样本点，观察拟合直线与残差平方和如何变化。本站是静态页面，这里用文字保留这个直觉，不影响后续推导。

### 2.8 CAPM 的局限性：为什么需要 APT？

CAPM 的最大问题在于：

它假设市场组合是唯一需要被定价的系统性风险来源。

但是，实际股票市场中存在很多无法仅仅通过市场 Beta 解释的收益差异。

例如：

- 小市值股票长期可能具有不同的平均收益表现。
- 高账面市值比股票与低账面市值比股票的收益存在系统性差异。
- 某些宏观经济变量可能对不同企业产生不同影响。

如果 CAPM 是完整的定价模型，那么在控制市场 Beta 后，不应该再出现能够稳定解释平均收益率的其他风险暴露。

但大量实证研究发现，情况并非如此。

这意味着：

**单一市场因子可能不足以解释资产的横截面收益差异。**

由此引出了 APT。

## 第三部分：APT——从单因子定价走向多因子定价

CAPM 的困境是只有一个风险来源。APT 换了一条路：不假设市场组合，只要求收益率由多个共同因子驱动，并且不存在套利机会。这一部分先用数值例子建立直觉，再用线性代数推一遍，说明线性定价关系从哪里来，以及 APT 为什么没有直接给出因子清单。

### 3.1 APT 是什么？

APT，全称 Arbitrage Pricing Theory，即套利定价理论。

Stephen Ross 于 1976 年发表了经典论文：

*The Arbitrage Theory of Capital Asset Pricing.*

APT 的核心思想是：

如果资产收益率由多个共同风险因素驱动，并且市场中不存在可以持续获得无风险利润的套利机会，那么资产的预期收益率应该与这些风险因素的暴露呈近似线性关系。

与 CAPM 相比，APT 最重要的变化是：

CAPM 从市场均衡和有效市场组合出发。

APT 则从多因子收益生成过程与无套利条件出发。

它不要求必须找到一个理论上完整的市场组合。

### 3.2 APT 的第一步：建立多因子收益生成模型

假设一只股票的收益率受到三个因素影响：

1. 宏观经济增长冲击。
2. 通货膨胀冲击。
3. 利率变化冲击。

那么我们可以建立：

\[ R_i=E(R_i)+ \beta_{i1}F_1+ \beta_{i2}F_2+ \beta_{i3}F_3+ \epsilon_i \]

其中：

- \(F_1\)：经济增长因子。
- \(F_2\)：通货膨胀因子。
- \(F_3\)：利率因子。
- \(\beta_{ik}\)：资产 \(i\) 对第 \(k\) 个因子的暴露。
- \(\epsilon_i\)：资产自身的特有扰动。

这里的 \(F_k\) 通常是经过中心化的因子冲击：

\[ E(F_k)=0 \]

所以：

\[ E(R_i) \]

就是资产的预期收益率。

更一般地，APT 的因子收益生成模型可以写为：

\[ R_i= E(R_i)+ \sum_{k=1}^{K}\beta_{ik}F_k+ \epsilon_i \]

与 CAPM 相比，APT 不再限制 \(K=1\)。

这就是从单因子到多因子的第一步。

### 3.3 APT 的核心：为什么无套利能够推导出线性定价关系？

这一部分是 APT 最重要、也最容易被忽略的理论内容。

我们通过一个简单例子理解。

假设市场中有三只股票：

| 股票 | 经济增长 Beta | 通胀 Beta | 预期收益率 |
|---|---:|---:|---:|
| A | 1 | 0 | 8% |
| B | 0 | 1 | 6% |
| C | 1 | 1 | 20% |

为了方便说明，先假设所有资产的初始投资成本均为 1。

现在构造一个组合：

- 买入一份 A。
- 买入一份 B。
- 卖空一份 C。

这里的“一份”可以理解为 1 元初始资金对应的头寸。组合权重为：

\[ \mathbf{w}= \begin{bmatrix} 1\\ 1\\ -1 \end{bmatrix} \]

这个组合的初始净投入为：

\[ 1+1-1=1 \]

它还不是零成本组合。要把净投入压到零，还需要一笔 1 元的无风险融资：借入 1 元，等价于在无风险资产上持有 \(-1\) 的头寸。完整的权重向量因此变成：

\[ \mathbf{w}= \begin{bmatrix} 1\\ 1\\ -1\\ -1 \end{bmatrix} \]

最后一行对应无风险资产。此时组合的初始净投资为：

\[ 1+1-1-1=0 \]

零成本的条件满足了，但这个组合并不是“什么都不做”。先观察它的系统性风险暴露。

经济增长因子暴露：

\[ 1\times1+1\times0-1\times1=0 \]

通胀因子暴露：

\[ 1\times0+1\times1-1\times1=0 \]

两个系统性因子的暴露全部抵消。

在分散化充分、特有风险能够消除的理想条件下，这个组合几乎没有系统性风险。

再看它的预期损益。记无风险利率为 \(r_f\)，上述零成本组合的预期损益是：

\[ E(R_A)+E(R_B)-E(R_C)-r_f \]

代入表中的数字：

\[ 8\%+6\%-20\%-r_f=-6\%-r_f\lt 0 \]

所以在给定的数字下，“买 A、买 B、卖空 C”的方向并不赚钱。真正能形成套利的是反方向：卖空 A 和 B、买入 C，同时把释放出来的 1 元按无风险利率贷出。反向组合的因子暴露是上面各项的相反数，仍然为零；初始净投资仍然为零；预期损益为：

\[ -8\%-6\%+20\%+r_f=6\%+r_f\gt 0 \]

这就构成了一个零成本、零系统性因子暴露、却有正预期收益的头寸。只要特有风险能够通过分散化消除，套利者就会执行它。

这个例子也直接给出了 APT 的定价形式。设：

\[ E(R_i)=\lambda_0+\beta_{i1}\lambda_1+\beta_{i2}\lambda_2 \]

由 A 和 B 的定价可以解出 \(\lambda_1=8\%-r_f=6\%\)、\(\lambda_2=6\%-r_f=4\%\)。如果取 \(\lambda_0=r_f=2\%\)，那么 C 的公允预期收益率应为：

\[ r_f+6\%+4\%=12\% \]

而表中给 C 的预期收益率是 20%，说明 C 被明显低估，买入 C 的套利方向与上面的计算完全一致。反过来，如果 C 的价格被抬到预期收益率只有 12%，套利空间就消失了。

套利者会不断买入被低估的资产、卖空被高估的资产，直到价格调整，使这种套利机会消失。

因此，在无套利均衡下：

**任何具有相同因子暴露的资产组合，都不能长期具有不同的预期收益率。**

这就是 APT 线性定价关系的经济直觉。

### 3.4 APT 的数学推导

现在进入正式推导。

假设有 \(N\) 个资产、\(K\) 个系统性因子。

收益率生成模型：

\[ R_i=E(R_i)+\boldsymbol{\beta}_i^T\mathbf{F}+\epsilon_i \]

其中：

\[ \boldsymbol{\beta}_i= \begin{bmatrix} \beta_{i1}\\ \beta_{i2}\\ \vdots\\ \beta_{iK} \end{bmatrix} \]

\[ \mathbf{F}= \begin{bmatrix} F_1\\ F_2\\ \vdots\\ F_K \end{bmatrix} \]

现在构造一个投资组合：

\[ R_p=\sum_{i=1}^{N}w_iR_i \]

代入收益率生成模型：

\[ R_p= \sum_iw_iE(R_i) + \sum_iw_i\boldsymbol{\beta}_i^T\mathbf{F} + \sum_iw_i\epsilon_i \]

整理：

\[ R_p= \sum_iw_iE(R_i) + \left(\sum_iw_i\boldsymbol{\beta}_i\right)^T \mathbf{F} + \sum_iw_i\epsilon_i \]

现在构造一个满足以下条件的组合：

**条件一：零成本组合**

\[ \sum_iw_i=0 \]

**条件二：零因子暴露**

\[ \sum_iw_i\boldsymbol{\beta}_i=\mathbf{0} \]

**条件三：特有风险充分分散**

\[ \sum_iw_i\epsilon_i\approx0 \]

那么：

\[ R_p\approx\sum_iw_iE(R_i) \]

这个组合的收益率几乎是确定的。

由于它是零成本组合，如果：

\[ \sum_iw_iE(R_i)>0 \]

就意味着存在正收益套利。

无套利条件要求：

\[ \sum_iw_iE(R_i)\approx0 \]

对于所有满足零成本、零因子暴露条件的组合，都必须成立。

在线性代数意义上，这意味着预期收益率向量必须落在常数向量与因子 Beta 向量所张成的空间中。

因此：

\[ E(R_i)=\lambda_0+ \sum_{k=1}^{K}\beta_{ik}\lambda_k \]

进一步，在存在无风险资产且满足相应假设时：

\[ \lambda_0=R_f \]

于是：

\[ \boxed{ E(R_i)=R_f+ \sum_{k=1}^{K}\beta_{ik}\lambda_k } \]

这就是 APT 的核心定价关系。

其中：

\[ \lambda_k \]

代表第 \(k\) 个因子的风险溢价。

需要强调：

APT 在有限资产、近似分散化和近似无套利的条件下，通常给出近似线性定价关系，而不是无条件保证精确线性关系。

### 3.5 APT 与 CAPM 的本质区别

| 比较维度 | CAPM | APT |
|---|---|---|
| 理论基础 | 市场均衡、均值方差优化 | 无套利 |
| 风险因子 | 单一市场因子 | 多个系统性因子 |
| 市场组合 | 核心概念 | 不要求显式使用理论市场组合 |
| 核心假设 | 投资者行为、共同预期等 | 因子结构、分散化、无套利 |
| Beta | 市场 Beta | 多个因子 Beta |
| 风险溢价 | 市场风险溢价 | 多个因子风险溢价 |
| 实际应用 | 基准资产定价 | 多因子定价理论基础 |

### 3.6 APT 的一个重要问题：因子从哪里来？

APT 解决了多因子定价的理论问题，但没有直接告诉我们应该选择哪些因子。

例如：

我们可以选择：

- GDP 增长。
- CPI 通胀。
- 利率变化。
- 信用利差。
- 流动性变化。

也可以选择其他能够解释资产收益共同变化的变量。

APT 并没有提供唯一的因子清单。

这意味着研究者必须进一步解决两个问题：

1. 如何识别真正重要的系统性因子？
2. 如何构造可以实际计算的因子收益率？

这也是后续 Fama-French 等实证因子模型发展的重要背景。

---

## 第四部分：Fama-French 多因子模型——从理论风险因子走向可观测因子组合

APT 说因子存在，却没说因子长什么样。Fama-French 的贡献是把“规模”“价值”这些可观测特征变成可交易的因子收益率：通过双重排序构造 SMB 与 HML，再用时间序列回归检验它们能否解释收益。这一部分也会解释，为什么用组合收益率而不是直接用公司特征。

### 4.1 为什么需要 Fama-French 模型？

在 CAPM 中，市场 Beta 是唯一的系统性风险暴露。

但是，美国股票市场的实证研究发现，市场 Beta 并不能充分解释股票平均收益率的横截面差异。

其中最经典的两个现象是：

**规模效应（Size Effect）**

小市值公司股票的长期平均收益率，在一些历史样本中高于大市值公司。

**价值效应（Value Effect）**

高账面市值比股票的长期平均收益率，在一些历史样本中高于低账面市值比股票。

这里的账面市值比：

\[ B/M= \frac{\text{Book Equity}}{\text{Market Equity}} \]

例如：

公司 A：

- 账面权益：100 亿美元。
- 市值：1000 亿美元。

\[ B/M=0.1 \]

公司 B：

- 账面权益：100 亿美元。
- 市值：200 亿美元。

\[ B/M=0.5 \]

公司 B 的账面市值比更高。

这类股票通常被归类为价值型股票。

Fama 和 French 在 1993 年的经典论文：

*Common Risk Factors in the Returns on Stocks and Bonds*

提出了三因子模型。

该模型将市场因子、规模因子和价值因子结合起来。

### 4.2 Fama-French 三因子模型

经典 FF3 模型：

\[ \boxed{ R_{i,t}-R_{f,t} = \alpha_i+ \beta_{i,MKT}MKT_t+ \beta_{i,SMB}SMB_t+ \beta_{i,HML}HML_t+ \epsilon_{i,t} } \]

其中：

| 因子 | 全称 | 代表含义 |
|---|---|---|
| MKT | Market Excess Return | 市场超额收益 |
| SMB | Small Minus Big | 小市值减大市值 |
| HML | High Minus Low | 高账面市值比减低账面市值比 |

这三个因子都可以作为时间序列中的因子收益率。

注意一个重要区别：

在 FF3 中，SMB 和 HML 并不是简单地将市值和账面市值比直接放入回归。

它们是通过股票组合构建出来的因子收益率。

这也是 Fama-French 模型区别于简单宏观变量回归的重要地方。

### 4.3 市场因子 MKT 如何构建？

市场因子：

\[ \boxed{ MKT_t=R_{M,t}-R_{f,t} } \]

其中：

- \(R_{M,t}\)：市场组合收益率。
- \(R_{f,t}\)：无风险利率。

例如：

美国市场组合当月收益率为 2%。

无风险利率为 0.3%。

那么：

\[ MKT=2\%-0.3\%=1.7\% \]

市场因子代表股票市场整体的超额收益。

### 4.4 规模因子 SMB 如何构建？

SMB：

\[ \boxed{ SMB=Small-Big } \]

它的构造逻辑是：

小市值股票组合收益率减去大市值股票组合收益率。

例如：

| 组合 | 月收益率 |
|---|---:|
| 小市值股票组合 | 3.0% |
| 大市值股票组合 | 1.5% |

那么：

\[ SMB=3.0\%-1.5\%=1.5\% \]

如果 SMB 为正，意味着当期小市值组合表现优于大市值组合。

如果 SMB 为负，则意味着当期大市值组合表现更好。

#### Fama-French 的经典构建方法

经典美国股票三因子模型采用规模和账面市值比进行双重排序。

首先：

根据股票市值划分为两组：

- Small。
- Big。

然后：

根据账面市值比分为三组：

- Low。
- Neutral。
- High。

形成六个组合：

| | Low B/M | Neutral B/M | High B/M |
|---|---|---|---|
| Small | S/L | S/N | S/H |
| Big | B/L | B/N | B/H |

然后计算：

\[ SMB= \frac{S/L+S/N+S/H}{3} - \frac{B/L+B/N+B/H}{3} \]

这里的每个符号代表对应组合在当期的收益率。

这相当于：

小市值股票三个价值类别的平均收益率，减去大市值股票三个价值类别的平均收益率。

这样做的好处是：

尽量避免 SMB 完全受到价值特征差异的影响。

也就是说，构造规模因子时，尽可能控制价值维度。

### 4.5 价值因子 HML 如何构建？

HML：

\[ \boxed{ HML=High-Low } \]

其含义：

高账面市值比股票组合收益率减去低账面市值比股票组合收益率。

按照上述六个组合：

\[ HML= \frac{S/H+B/H}{2} - \frac{S/L+B/L}{2} \]

假设：

| 组合 | 月收益率 |
|---|---:|
| S/H | 3.5% |
| B/H | 2.5% |
| S/L | 1.0% |
| B/L | 1.5% |

那么：

\[ HML= \frac{3.5\%+2.5\%}{2} - \frac{1.0\%+1.5\%}{2} \]

\[ =3.0\%-1.25\% \]

\[ =1.75\% \]

这意味着当月价值组合相对于成长组合取得了 1.75% 的超额收益。

### 4.6 为什么要使用组合收益率构建因子，而不是直接使用公司特征？

这是一个非常值得理解的问题。

假设我有 1000 只股票，每只股票都有：

- 市值。
- 账面市值比。
- 营收增长率。
- 盈利能力。

我可以直接将这些变量放入一个回归：

\[ R_i= \alpha+ \beta_1Size_i+ \beta_2B/M_i+ \epsilon_i \]

但这与经典 Fama-French 因子模型不是一回事。

原因在于：

公司特征是资产的横截面属性。

因子收益率是市场在某个时期实际实现的因子组合收益。

两者有联系，但不能直接等同。

例如：

某只股票具有很高的账面市值比，并不意味着 HML 当月一定为正。

HML 是整个市场中高账面市值比组合相对于低账面市值比组合的实际收益差。

因此：

- B/M 是股票特征。
- HML 是因子组合收益率。
- \(\beta_{HML}\) 是股票对 HML 因子收益变化的敏感程度。
- \(\lambda_{HML}\) 是 HML 的预期风险溢价。

这四个概念必须区分清楚。

### 4.7 使用 FF3 进行时间序列回归

现在我已经拥有了：

- 股票收益率。
- 无风险利率。
- MKT。
- SMB。
- HML。

就可以估计：

\[ R_{i,t}-R_{f,t} = \alpha_i+ \beta_{i,MKT}MKT_t+ \beta_{i,SMB}SMB_t+ \beta_{i,HML}HML_t+ \epsilon_{i,t} \]

假设回归结果如下：

\[ \begin{aligned} R_i-R_f={}&0.001\\ &+1.20MKT\\ &+0.65SMB\\ &+0.80HML+\epsilon \end{aligned} \]

那么：

| 参数 | 结果 | 解释 |
|---|---:|---|
| Alpha | 0.001 | 未被三个因子解释的月度收益部分 |
| MKT Beta | 1.20 | 对市场风险较敏感 |
| SMB Beta | 0.65 | 偏向小市值股票的收益特征 |
| HML Beta | 0.80 | 偏向价值股票的收益特征 |

这只股票的收益表现同时具有市场、小市值和价值因子暴露。

这里要注意：

Beta 为正，表示股票收益与相应因子收益具有正向线性关系。

Beta 并不是该因子的风险溢价。

例如：

\[ \beta_{SMB}=0.65 \]

并不意味着规模因子的风险溢价为 65%。

它表示的是资产对规模因子收益变化的敏感度。

### 4.8 FF3 与 CAPM 的比较

CAPM：

\[ R_i-R_f=\alpha_i+\beta_{MKT}MKT+\epsilon_i \]

FF3：

\[ R_i-R_f= \alpha_i+ \beta_{MKT}MKT+ \beta_{SMB}SMB+ \beta_{HML}HML+ \epsilon_i \]

FF3 比 CAPM 多了两个因子。

那么如何判断 FF3 是否更好？

通常需要考察：

1. 回归残差是否降低。
2. 调整后 \(R^2\) 是否提高。
3. CAPM 中显著的 Alpha 是否在 FF3 中消失。
4. 新增因子的 Beta 是否具有统计显著性。
5. 因子是否能够解释不同股票组合的平均收益差异。
6. 模型在样本外是否仍然具有解释能力。

但需要特别强调：

调整后 \(R^2\) 提高，并不意味着模型一定具有更强的资产定价能力。

因为增加解释变量通常能够提高样本内拟合程度。

资产定价模型更重要的检验目标，是它能否解释资产之间的预期收益率差异，而不只是解释单只股票收益率的时间序列波动。

这就引出了 Fama-MacBeth 回归。

---

## 第五部分：Fama-MacBeth 截面回归——从时间序列 Beta 到因子风险溢价

时间序列回归只能告诉我们某只资产对因子有多敏感，不能告诉我们市场为这份敏感付了多少钱。Fama-MacBeth 用两次回归补上后半句：先估 Beta，再逐期做截面回归估 Gamma，最后对 Gamma 的时间序列做推断。

### 5.1 为什么时间序列回归还不够？

前面我们使用 CAPM 和 FF3 进行时间序列回归。

例如：

\[ R_{i,t}-R_{f,t} = \alpha_i+ \beta_{i,MKT}MKT_t+ \beta_{i,SMB}SMB_t+ \beta_{i,HML}HML_t+ \epsilon_{i,t} \]

这类回归可以告诉我们：

某只股票对不同因子的暴露程度是多少。

但是，它不能直接回答：

**承担更多规模风险的股票，是否真的获得了更高的平均收益率？**

举例：

| 股票 | SMB Beta | 长期平均超额收益率 |
|---|---:|---:|
| A | 0.2 | 5% |
| B | 0.5 | 8% |
| C | 1.0 | 12% |
| D | 1.5 | 15% |

从表面上看，SMB Beta 越高，股票平均收益率越高。

但是，这只是一个观察结果。

我们还需要进一步控制市场 Beta、价值 Beta 等其他因素。

否则无法判断规模因子是否真的具有独立的定价能力。

这就是截面回归要解决的问题。

### 5.2 时间序列回归与截面回归的区别

这是整个学习体系中最重要的概念之一。

#### 时间序列回归（Time-Series Regression）

研究对象：

一只资产在不同时间的收益率。

例如：

使用某只股票过去 120 个月的数据，估计它的：

- 市场 Beta。
- SMB Beta。
- HML Beta。

形式：

\[ R_{i,t}-R_{f,t} = \alpha_i+ \sum_{k=1}^{K}\beta_{ik}F_{k,t} + \epsilon_{i,t} \]

固定资产 \(i\)，观察时间 \(t\) 的变化。

#### 截面回归（Cross-Sectional Regression）

研究对象：

同一个时间点，不同资产之间的收益率差异。

例如：

2025 年 1 月，我有 1000 只股票。

我希望研究：

这些股票的市场 Beta、SMB Beta、HML Beta，是否能够解释它们当月收益率的差异？

形式：

\[ R_{i,t}-R_{f,t} = \gamma_{0,t} + \sum_{k=1}^{K}\gamma_{k,t}\beta_{ik} + u_{i,t} \]

固定时间 \(t\)，观察不同资产 \(i\) 的差异。

这里：

- \(\beta_{ik}\)：资产对第 \(k\) 个因子的暴露。
- \(\gamma_{k,t}\)：第 \(t\) 期市场给予第 \(k\) 个因子暴露的风险价格。
- \(u_{i,t}\)：截面回归残差。

这是一个非常关键的概念：

**Beta 衡量风险暴露，Gamma 衡量市场对这种风险暴露所支付的价格。**

两者不是同一个东西。

### 5.3 Fama-MacBeth 方法是什么？

Fama-MacBeth 方法由 Eugene Fama 和 James MacBeth 于 1973 年提出。

经典论文：

*Risk, Return, and Equilibrium: Empirical Tests.*

它的核心思想是：

将时间序列 Beta 估计与横截面风险溢价估计结合起来，通过逐期截面回归，获得风险溢价的时间序列。

它通常被称为两阶段回归（Two-Pass Regression）。

这里的“两阶段”指的是两次回归：第一阶段做时间序列回归，估计每只资产的因子暴露；第二阶段做逐期截面回归，估计每一期市场对这些暴露给出的风险价格。至于把各期 Gamma 求平均、再构造 t 统计量，属于第二阶段之后的推断步骤，不是第三次回归。很多教材把这一整套流程统称为 Fama-MacBeth 回归，严格说它是“两次回归 + 一次时间序列推断”。

需要注意：

第一阶段估计的是资产的风险暴露。

第二阶段估计的是市场对这些风险暴露的定价。

### 5.4 第一阶段：时间序列回归，估计每只股票的 Beta

假设我有 1000 只美国股票。

历史数据覆盖 120 个月。

首先，对每只股票进行 FF3 时间序列回归：

\[ R_{i,t}-R_{f,t} = \alpha_i+ \beta_{i,MKT}MKT_t+ \beta_{i,SMB}SMB_t+ \beta_{i,HML}HML_t+ \epsilon_{i,t} \]

对每只股票都进行一次回归。

最终得到：

| 股票 | MKT Beta | SMB Beta | HML Beta |
|---|---:|---:|---:|
| A | 0.8 | 0.2 | 0.1 |
| B | 1.1 | 0.8 | 0.3 |
| C | 1.3 | 0.5 | 0.9 |
| D | 0.7 | 1.2 | 1.1 |
| E | 1.5 | 1.0 | 0.2 |

这张表就是第一阶段的核心输出。

它表示：

每只股票分别暴露于多少市场风险、规模风险和价值风险。

这里得到的 Beta 通常使用历史滚动窗口或形成期数据估计。

如果使用 120 个月的数据，就需要保证这些数据在第二阶段的收益实现之前已经可获得，否则会引入前视偏差。

### 5.5 第二阶段：逐期截面回归，估计风险溢价

假设第一阶段已经得到所有股票的 Beta。

现在观察 2025 年 1 月。

我们对所有股票进行一次截面回归：

\[ \begin{aligned} R_{i,t}-R_{f,t} ={}&\gamma_{0,t}\\ &+\gamma_{MKT,t}\hat{\beta}_{i,MKT}\\ &+\gamma_{SMB,t}\hat{\beta}_{i,SMB}\\ &+\gamma_{HML,t}\hat{\beta}_{i,HML}\\ &+u_{i,t} \end{aligned} \]

这次回归与第一阶段完全不同。

第一阶段：

用时间序列变化估计 Beta。

第二阶段：

用同一时点不同股票之间的收益差异，估计 Gamma。

假设回归结果为：

\[ \begin{aligned} R_{i,t}-R_{f,t} ={}&0.002\\ &+0.005\hat{\beta}_{i,MKT}\\ &+0.003\hat{\beta}_{i,SMB}\\ &+0.004\hat{\beta}_{i,HML} +u_{i,t} \end{aligned} \]

那么：

| 参数 | 结果 | 解释 |
|---|---:|---|
| \(\gamma_{0,t}\) | 0.002 | 当期截距 |
| \(\gamma_{MKT,t}\) | 0.005 | 当期市场风险价格 |
| \(\gamma_{SMB,t}\) | 0.003 | 当期规模风险价格 |
| \(\gamma_{HML,t}\) | 0.004 | 当期价值风险价格 |

这些 Gamma 是当期截面回归估计出来的风险价格。

如果：

\[ \gamma_{SMB,t}>0 \]

那么在当期截面中，承担更多 SMB 风险暴露的股票，具有更高的收益率。

但我们不能仅仅观察一个月就得出规模因子有效的结论。

需要在很多个月份重复这一过程。

### 5.6 第三步：对每一期的 Gamma 求时间平均

假设研究窗口为 120 个月。

我们得到：

\[ \gamma_{MKT,1}, \gamma_{MKT,2}, \ldots, \gamma_{MKT,120} \]

对它们求时间平均：

\[ \boxed{ \bar{\gamma}_{MKT} = \frac{1}{T} \sum_{t=1}^{T}\gamma_{MKT,t} } \]

同理：

\[ \bar{\gamma}_{SMB} = \frac{1}{T} \sum_{t=1}^{T}\gamma_{SMB,t} \]

\[ \bar{\gamma}_{HML} = \frac{1}{T} \sum_{t=1}^{T}\gamma_{HML,t} \]

最终得到：

| 因子 | 平均风险溢价 |
|---|---:|
| MKT | 0.60% |
| SMB | 0.25% |
| HML | 0.40% |

这里假设单位是月度收益率。

那么研究者可以初步认为：

- 市场因子平均风险价格为正。
- 规模因子平均风险价格为正。
- 价值因子平均风险价格为正。

但是，还必须进行统计显著性检验。

### 5.7 Fama-MacBeth 的 t 统计量

这是整个方法最关键的统计检验环节。

我们希望检验：

规模因子的平均风险溢价是否显著大于 0？

建立假设：

\[ H_0:E(\gamma_{SMB})=0 \]

\[ H_1:E(\gamma_{SMB})\neq0 \]

先计算平均值：

\[ \bar{\gamma}_{SMB} = \frac{1}{T} \sum_{t=1}^{T}\gamma_{SMB,t} \]

再计算时间序列标准差：

\[ s_{\gamma} = \sqrt{ \frac{ \sum_{t=1}^{T} (\gamma_{SMB,t}-\bar{\gamma}_{SMB})^2 }{ T-1 } } \]

均值标准误：

\[ SE(\bar{\gamma}_{SMB}) = \frac{s_{\gamma}}{\sqrt{T}} \]

于是：

\[ \boxed{ t_{SMB} = \frac{ \bar{\gamma}_{SMB} }{ s_{\gamma}/\sqrt{T} } } \]

假设：

- 平均 SMB 风险溢价：0.25%。
- 逐期 Gamma 的标准差：1.0%。
- 样本月份：100 个月。

那么：

\[ SE=\frac{1.0\%}{\sqrt{100}}=0.1\% \]

因此：

\[ t=\frac{0.25\%}{0.1\%}=2.5 \]

在通常的双侧检验标准下，这一结果具有统计显著性。

这意味着：

我们有一定统计证据认为，规模因子的平均风险价格不为零。

不过，在实际研究中，还要考虑 Gamma 序列的自相关和异方差问题，必要时采用 Newey-West 等稳健标准误。

### 5.8 为什么 Fama-MacBeth 要进行逐期截面回归？

这是很多初学者容易产生疑问的地方。

为什么不直接把所有股票、所有月份的数据放在一起，做一次普通 OLS？

因为金融数据具有两个维度：

- 时间维度。
- 资产截面维度。

不同月份的风险价格可能不同。

例如：

| 月份 | SMB 风险价格 |
|---|---:|
| 1 月 | 0.5% |
| 2 月 | -0.2% |
| 3 月 | 0.8% |
| 4 月 | -0.5% |
| 5 月 | 0.4% |

如果把所有数据混在一起，直接做一次回归，就可能掩盖风险价格随时间变化的特征。

Fama-MacBeth 的做法是：

1. 每个月独立估计一次截面风险价格。
2. 得到一条风险价格时间序列。
3. 对这条时间序列求均值。
4. 检验平均风险价格是否显著。

它的统计推断思路非常重要：

**我们最终关心的不是某一个月份的风险价格，而是风险价格在整个研究期间的平均水平。**

### 5.9 Fama-MacBeth 的完整数学结构

第一阶段：

\[ R_{i,t} = \alpha_i+ \sum_{k=1}^{K}\beta_{ik}F_{k,t} +\epsilon_{i,t} \]

估计：

\[ \hat{\beta}_{ik} \]

第二阶段：

\[ R_{i,t} = \gamma_{0,t} + \sum_{k=1}^{K} \gamma_{k,t}\hat{\beta}_{ik} + u_{i,t} \]

第三阶段：

\[ \bar{\gamma}_k= \frac{1}{T} \sum_{t=1}^{T}\gamma_{k,t} \]

统计检验：

\[ t(\bar{\gamma}_k) = \frac{\bar{\gamma}_k} {s(\gamma_k)/\sqrt{T}} \]

最终得到每个因子的：

- 平均风险溢价。
- 标准误。
- t 统计量。
- p 值。
- 置信区间。

这就是标准的 Fama-MacBeth 两阶段回归框架。

## 第六部分：必须分清楚的几个回归概念

Fama-MacBeth 的公式不难，难的是不把几个长得很像的概念混在一起。这一部分用对照表把时间序列回归与截面回归、Beta 与 Gamma、Alpha 与风险溢价、统计显著性与经济显著性逐对拆开。

### 6.1 时间序列回归不等于截面回归

| 对比 | 时间序列回归 | 截面回归 |
|---|---|---|
| 观察对象 | 同一资产的不同时间 | 同一时间的不同资产 |
| 因变量 | 资产收益率 | 资产收益率 |
| 自变量 | 因子收益率 | 因子 Beta 或资产特征 |
| 核心估计结果 | Beta | Gamma |
| 主要用途 | 估计风险暴露 | 估计风险价格 |

### 6.2 Beta 与 Gamma 的区别

这两个概念必须彻底掌握。

假设：

\[ \beta_{i,SMB}=1.5 \]

说明股票 \(i\) 对 SMB 因子的敏感程度较高。

但它是否应该获得更高的预期收益率，还取决于：

\[ \lambda_{SMB} \]

如果：

\[ \lambda_{SMB}=0.5\% \]

那么股票由于 SMB 暴露获得的预期收益补偿为：

\[ 1.5\times0.5\%=0.75\% \]

在这里：

- Beta 是数量上的风险暴露。
- Lambda 或 Gamma 是单位风险暴露对应的价格。
- Beta × Lambda 是风险暴露对应的收益补偿。

### 6.3 Alpha 与风险溢价不是一回事

Alpha：

衡量资产实际平均收益率与模型所预测收益率之间的差异。

风险溢价：

衡量市场为承担某种系统性风险支付的预期补偿。

例如：

某只股票的 FF3 Alpha 显著为正，意味着 FF3 未能完全解释它的平均收益率。

而 SMB 风险溢价显著为正，则意味着承担更多 SMB 风险暴露的股票，平均获得了更高的收益率。

这是两个不同的研究结论。

### 6.4 统计显著性与经济显著性

假设：

\[ \bar{\gamma}_{SMB}=0.02\% \]

t 统计量：

\[ t=3.5 \]

虽然统计显著，但它的经济收益可能非常有限。

反过来：

\[ \bar{\gamma}_{SMB}=1.0\% \]

但由于样本数量不足，t 统计量只有 1.2。

那么它虽然具有较大的经济量级，但统计证据不足。

因此，一个完整的因子研究至少需要同时考察：

1. 经济显著性（Economic Significance）。
2. 统计显著性（Statistical Significance）。

## 第七部分：Fama-French 模型的进一步扩展

FF3 之后，文献继续往两个方向扩展：一是加入盈利与投资因子形成 FF5，二是用动量、q-factor 等替代设定解释同样的异象。这一部分梳理这些扩展的动机与差别——不要求记住所有模型，但要理解它们各自想修补什么。

### 7.1 FF3 到 FF5

2015 年，Fama 和 French 提出了五因子模型。

经典 FF5 模型：

\[ \begin{aligned} R_i-R_f={}& \alpha_i+ \beta_{MKT}MKT\\ &+\beta_{SMB}SMB\\ &+\beta_{HML}HML\\ &+\beta_{RMW}RMW\\ &+\beta_{CMA}CMA+\epsilon_i \end{aligned} \]

新增两个因子。

#### RMW：Robust Minus Weak

盈利能力因子。

代表高经营盈利能力公司与低经营盈利能力公司的收益差。

\[ RMW=Robust-Weak \]

#### CMA：Conservative Minus Aggressive

投资因子。

代表低资产增长、保守投资公司与高资产增长、激进投资公司的收益差。

\[ CMA=Conservative-Aggressive \]

这意味着 Fama-French 将股票的收益特征扩展到了：

- 市场风险。
- 公司规模。
- 价值特征。
- 盈利能力。
- 投资行为。

### 7.2 FF3 与 FF5 的区别

| 因子 | 研究维度 | 主要经济含义 |
|---|---|---|
| MKT | 市场 | 整体市场风险 |
| SMB | 规模 | 小公司与大公司的收益差 |
| HML | 价值 | 价值股与成长股的收益差 |
| RMW | 盈利能力 | 高盈利与低盈利公司的收益差 |
| CMA | 投资 | 保守投资与激进投资公司的收益差 |

需要注意：

FF5 并不意味着每一个新增因子都一定能够在所有市场、所有时期产生显著溢价。

例如，HML 在 FF5 中的解释能力会受到 RMW 和 CMA 的影响。

模型的因子数量增加，不代表模型必然更优。

### 7.3 其他重要的因子模型

除了 FF3 和 FF5，还需要了解以下模型：

| 模型 | 新增因子 | 主要研究方向 |
|---|---|---|
| Carhart 四因子 | MOM | 动量效应 |
| Fama-French 五因子 | RMW、CMA | 盈利能力与投资 |
| Hou-Xue-Zhang q-factor | ME、IA、ROE、EG | 投资与盈利能力 |
| Stambaugh-Yuan | MGMT、PERF | 管理与绩效特征 |

其中 Carhart 四因子模型：

\[ \begin{aligned} R_i-R_f={}& \alpha_i+ \beta_{MKT}MKT\\ &+\beta_{SMB}SMB\\ &+\beta_{HML}HML\\ &+\beta_{MOM}MOM+\epsilon_i \end{aligned} \]

MOM 是动量因子（Momentum）。

它通常通过过去一段时间表现较好的股票减去表现较差的股票构建。

动量因子值得单独研究，因为它与传统的市场、规模、价值因子具有不同的经济特征。

## 第八部分：资产定价实证研究中常见的检验方法

前面已经学习了模型的理论结构。

现在需要建立一个完整的实证检验框架。

这里将几种经常使用的方法放在一起。

### 8.1 单因子时间序列回归

模型：

\[ R_{i,t}-R_{f,t} = \alpha_i+\beta_iF_t+\epsilon_{i,t} \]

研究目标：

- 估计 Beta。
- 检验 Alpha 是否显著。
- 观察单个因子对资产收益率的解释能力。

适用场景：

研究一个因子是否能够解释资产收益的时间序列变化。

### 8.2 多因子时间序列回归

模型：

\[ R_{i,t}-R_{f,t} = \alpha_i+ \sum_{k=1}^{K}\beta_{ik}F_{k,t} +\epsilon_{i,t} \]

研究目标：

- 同时估计多个因子的 Beta。
- 分析因子暴露之间的关系。
- 检验新增因子是否具有增量解释能力。
- 检验 Alpha 是否仍然显著。

适用场景：

CAPM、FF3、FF5、Carhart 等模型的时间序列检验。

### 8.3 Fama-MacBeth 两阶段回归

研究目标：

- 第一阶段估计各资产 Beta。
- 第二阶段逐期估计各因子风险价格。
- 最后检验平均风险溢价。

适用场景：

研究因子暴露是否能够解释资产之间的平均收益差异。

### 8.4 分组排序法（Portfolio Sort）

这是经典资产定价研究中非常重要的方法。

例如：

我想检验规模因子是否有效。

首先根据股票市值，将股票从小到大排序。

然后分为五组：

- Q1：最小市值组。
- Q2。
- Q3。
- Q4。
- Q5：最大市值组。

计算每组的平均收益率。

如果规模效应成立，可能观察到：

\[ R_{Q1}>R_{Q2}>R_{Q3}>R_{Q4}>R_{Q5} \]

当然，真实市场不一定呈现严格单调关系。

还可以构造多空组合：

\[ R_{Long-Short}=R_{Q1}-R_{Q5} \]

然后检验该组合的平均收益率和 t 统计量。

#### 为什么分组排序很重要？

因为它具有直观的经济解释。

例如：

如果高动量组的未来收益显著高于低动量组，那么投资者可以直接理解为：

过去表现较好的股票，未来一段时间平均表现也更好。

这比单纯观察一个回归系数更容易解释。

### 8.5 Fama-MacBeth 与分组排序的区别

| 维度 | 分组排序 | Fama-MacBeth |
|---|---|---|
| 核心输入 | 因子或股票特征 | 资产 Beta 或特征 |
| 方法 | 排序形成组合 | 逐期截面回归 |
| 输出 | 分组收益差 | 风险价格 Gamma |
| 是否控制多个变量 | 可以通过双重排序等方式实现 | 可以直接加入多个解释变量 |
| 优点 | 直观、容易解释 | 能够同时控制多个变量 |
| 局限 | 分组边界和信息损失 | 回归设定与估计误差敏感 |

两者不是相互替代的关系。

在实际研究中，可以先用分组排序检验因子的基本效果，再使用 Fama-MacBeth 检验其截面定价能力。

## 第九部分：Fama-MacBeth 的实际研究细节与常见陷阱

知道方法不等于能做研究。这一部分讨论实操中最容易出问题的地方：Beta 的估计误差、为什么要先构建组合、标准误为什么要用 Newey-West、多重共线性、因子收益率与因子特征的混淆，以及前视偏差和幸存者偏差。

### 9.1 第一阶段 Beta 的估计误差

Fama-MacBeth 的一个重要问题是：

第一阶段估计的 Beta 并不是真实 Beta，而是带有估计误差的估计值。

\[ \hat{\beta}_{ik} = \beta_{ik}+v_{ik} \]

如果直接把估计出来的 Beta 放入第二阶段回归，可能产生误差变量偏差（Errors-in-Variables Bias）。

尤其在以下情况下，问题更严重：

- 时间序列样本较短。
- 股票波动率很高。
- 因子之间高度相关。
- 股票交易不活跃。

经典解决思路包括：

1. 使用更长的历史窗口估计 Beta。
2. 先将股票组合化，再估计组合 Beta。
3. 使用适当的误差变量修正。
4. 使用 Shanken 修正等方法处理特定条件下的两阶段估计误差。

### 9.2 为什么经典研究经常先构建投资组合，再做 Fama-MacBeth？

假设我有 1000 只股票。

如果直接估计每只股票的 Beta，可能存在大量估计噪声。

因此可以先按照股票特征进行分组。

例如：

- 按市值分成 10 组。
- 按账面市值比分成 10 组。

形成投资组合后，对组合收益率估计 Beta。

组合通常具有更低的特有波动率，Beta 估计可能更加稳定。

然后再对这些投资组合进行第二阶段截面回归。

这就是经典两阶段资产定价研究中的常见做法。

### 9.3 第二阶段回归的标准误问题

标准 Fama-MacBeth 方法使用逐期 Gamma 的时间序列标准差计算均值标准误。

但金融市场收益率经常存在：

- 时间序列自相关。
- 波动率聚集。
- 异方差。
- 结构性变化。

因此，不能机械地认为普通 t 统计量在所有情况下都可靠。

当 Gamma 序列存在显著自相关时，可以使用 Newey-West HAC 标准误。

其核心思想是：

在计算长期均值的不确定性时，将一定滞后阶数内的自协方差纳入考虑。

### 9.4 多重共线性

假设我同时使用：

- 市值。
- 流通市值。
- 总市值。
- 市值对数。

这些变量之间可能存在非常强的相关性。

放入同一个回归模型，就可能产生多重共线性（Multicollinearity）。

其表现包括：

- 回归系数不稳定。
- 标准误变大。
- t 统计量下降。
- 不同样本窗口的系数变化很大。

因此，建模之前应当检查：

\[ Corr(X_i,X_j) \]

也可以使用方差膨胀因子：

\[ VIF_j= \frac{1}{1-R_j^2} \]

其中 \(R_j^2\) 是将第 \(j\) 个解释变量对其他解释变量回归得到的决定系数。

VIF 越大，通常意味着多重共线性越严重。

### 9.5 因子收益率与因子特征不能混淆

这是从经典股票资产定价迁移到量化因子研究时特别容易出错的地方。

假设：

我构建了一个过去 20 日收益率因子。

它是一个股票特征：

\[ Momentum_{i,t} = \frac{P_{i,t}}{P_{i,t-20}}-1 \]

这并不直接等于动量因子收益率。

如果要构建动量多空因子收益率，可以：

1. 在每个时间点，根据 Momentum 对股票排序。
2. 买入高动量组。
3. 卖出低动量组。
4. 计算多空组合收益率。

即：

\[ MOM_t=R_{High,t}-R_{Low,t} \]

这时才得到一个时间序列因子收益率。

前者是特征，后者是因子组合收益。

两者可以通过定价模型联系起来，但不是同一对象。

### 9.6 前视偏差与幸存者偏差

实证资产定价研究必须注意：

**前视偏差（Look-Ahead Bias）**

不能使用研究时点尚未公开的信息。

例如：

某家公司 2024 年年报在 2025 年 3 月才公布。

那么不能在 2024 年 12 月的截面研究中，提前使用该年报中的账面权益数据。

**幸存者偏差（Survivorship Bias）**

不能只研究当前仍然上市的公司。

如果历史上已经退市的公司被删除，可能会高估历史策略表现。

**股票池变化**

研究者必须明确每个时点可投资的资产集合，而不能使用当前股票列表代替完整历史股票池。

## 第十部分：从经典资产定价迁移到加密货币因子研究

这一部分将前面学到的理论与实际量化研究联系起来。

经典 Fama-French 模型主要针对股票市场。

而加密货币市场具有不同的资产结构和交易机制。

因此不能直接把 SMB、HML 等传统股票因子照搬到加密货币市场。

但资产定价理论和实证检验方法仍然具有参考价值。

### 10.1 加密货币市场与股票市场的区别

| 维度 | 股票市场 | 加密货币现货市场 |
|---|---|---|
| 资产性质 | 企业股权 | 加密资产 |
| 估值基础 | 盈利、资产、现金流等 | 网络效应、供需、使用价值、市场预期等 |
| 交易时间 | 通常有交易时段 | 24 小时连续交易 |
| 无风险利率 | 可使用国债利率代理 | 需要明确基准资产及计息口径 |
| 资产数量 | 相对稳定 | 新币持续上市，退市也频繁 |
| 数据可得性 | 公司财务数据丰富 | 早期主要依赖量价数据 |
| 市场结构 | 交易所、做市商等 | 多交易所、链上市场、做市商等 |

所以，在加密货币市场中，我们需要重新思考：

哪些变量代表系统性风险？

哪些因子具有稳定的收益溢价？

哪些因子只是暂时的市场现象？

### 10.2 加密货币市场可以如何构建多因子模型？

如果暂时只使用现货市场的价格和成交量数据，可以考虑以下方向。

| 因子类别 | 因子示例 | 经济解释 |
|---|---|---|
| 市场因子 | 全市场加权收益率 | 整体市场风险 |
| 动量因子 | 20 日、60 日、120 日动量 | 价格趋势延续 |
| 反转因子 | 短期收益率反转 | 短期价格修正 |
| 波动率因子 | 历史实现波动率 | 价格不确定性 |
| 流动性因子 | 成交额、Amihud 类指标 | 流动性风险 |
| 成交量因子 | 成交量变化率、量价背离 | 市场参与度变化 |
| 尾部风险因子 | 下行波动率、极端回撤 | 极端风险暴露 |
| 价格区间因子 | 区间突破、价格位置 | 趋势与区间状态 |

这些是候选研究方向，而不是已经得到验证的风险因子清单。

### 10.3 一个加密货币市场的多因子模型示例

假设我有：

- 100 种加密货币。
- 每日收盘价。
- 每日成交量。
- 每日成交额。
- 每日收益率。

首先构造市场因子：

\[ MKT_t= R_{Market,t} \]

这里可以采用按市值或其他明确规则构造的市场组合收益率。

然后构造动量因子：

\[ MOM_t= R_{HighMomentum,t} - R_{LowMomentum,t} \]

构造流动性因子：

\[ LIQ_t= R_{HighIlliquidity,t} - R_{LowIlliquidity,t} \]

构造低波动率因子：

\[ LOWVOL_t= R_{LowVolatility,t} - R_{HighVolatility,t} \]

最终：

\[ \begin{aligned} R_{i,t}-R_{f,t} ={}&\alpha_i+ \beta_{i,MKT}MKT_t\\ &+\beta_{i,MOM}MOM_t\\ &+\beta_{i,LIQ}LIQ_t\\ &+\beta_{i,LOWVOL}LOWVOL_t\\ &+\epsilon_{i,t} \end{aligned} \]

这就是一个加密货币四因子时间序列定价模型的研究框架。

但要特别注意：

加密货币市场缺少与传统股票市场完全对应的统一无风险资产。

如果采用 USDT 或 USDC 作为计价和基准，需要明确其利率假设、脱锚风险和交易场所差异。

在很多加密货币实证研究中，也可以先研究原始收益率或相对市场收益率，而不是直接套用传统市场的无风险利率设定。

### 10.4 如何使用 Fama-MacBeth 检验加密货币因子？

假设我有 100 种加密货币。

第一阶段：

利用过去 180 日的因子收益率，对每种币分别进行时间序列回归。

得到：

\[ \hat{\beta}_{i,MKT}, \hat{\beta}_{i,MOM}, \hat{\beta}_{i,LIQ} \]

第二阶段：

在每个交易日，对 100 种币进行截面回归：

\[ \begin{aligned} R_{i,t+1} ={}&\gamma_{0,t}\\ &+\gamma_{MKT,t}\hat{\beta}_{i,MKT}\\ &+\gamma_{MOM,t}\hat{\beta}_{i,MOM}\\ &+\gamma_{LIQ,t}\hat{\beta}_{i,LIQ}\\ &+u_{i,t+1} \end{aligned} \]

最后：

计算各因子风险价格的时间序列均值、标准误和 t 统计量。

这样就可以检验：

- 市场风险暴露是否具有风险溢价。
- 动量风险暴露是否具有风险溢价。
- 流动性风险暴露是否具有风险溢价。

#### 这里有一个需要特别注意的问题

传统 Fama-MacBeth 两阶段回归并不一定适合所有低频量价因子。

原因包括：

1. 加密货币资产数量较少时，截面回归容易不稳定。
2. 资产上市、退市会造成样本结构变化。
3. 加密货币收益率存在较强的横截面相关性。
4. 许多因子 Beta 会随市场状态发生变化。
5. 滚动估计窗口与预测窗口必须严格对齐。

尤其当资产数量较少、因子数量较多时，截面回归可能存在自由度不足的问题。

因此，应当结合分组排序、时间序列检验、Fama-MacBeth 和样本外检验共同判断。

## 第十一部分：Python 实现——从数据到 Fama-MacBeth 回归

理论部分结束后，这一部分把前面的两步回归写成可运行的 Python：整理长表、滚动估 Beta、逐期截面回归、对 Gamma 求均值与 t 值，最后用 Newey-West 修正标准误。代码刻意保持最小实现，方便逐行对照公式。

下面使用 pandas 和 statsmodels 构建一个简化的实证研究框架。

假设已经有两个数据表：

**资产收益率表 returns：**

| date | asset | ret |
|---|---|---:|
| 2024-01-01 | BTC | 0.02 |
| 2024-01-01 | ETH | 0.03 |
| 2024-01-02 | BTC | -0.01 |

**因子收益率表 factors：**

| date | MKT | MOM | LIQ |
|---|---:|---:|---:|
| 2024-01-01 | 0.015 | 0.010 | 0.005 |
| 2024-01-02 | -0.008 | -0.002 | 0.003 |

### 11.1 数据准备

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm

# 资产收益率数据
# columns: date, asset, ret

# 因子收益率数据
# columns: date, MKT, MOM, LIQ

returns["date"] = pd.to_datetime(returns["date"])
factors["date"] = pd.to_datetime(factors["date"])

# 合并数据
data = returns.merge(

    on="date",
    how="inner"

```

这里需要确保：

- 收益率定义一致。
- 因子收益率和资产收益率使用相同的频率。
- 数据没有未来信息。
- 日期对齐正确。

### 11.2 第一阶段：时间序列回归

```python
factor_cols = ["MKT", "MOM", "LIQ"]

beta_records = []

for asset, group in data.groupby("asset"):

    group = group.dropna(
        subset=["ret"] + factor_cols
    )

    if len(group) < 60:
        continue

    X = sm.add_constant(
        group[factor_cols]
    )

    y = group["ret"]

    model = sm.OLS(y, X).fit()

    beta_records.append({
        "asset": asset,
        "alpha": model.params["const"],
        "beta_MKT": model.params["MKT"],
        "beta_MOM": model.params["MOM"],
        "beta_LIQ": model.params["LIQ"]
    })

betas = pd.DataFrame(beta_records)
```

这里的代码是静态样本估计的基础示例。

正式研究中，应使用滚动窗口估计 Beta，并保证 Beta 只使用预测时点之前的数据。

### 11.3 第二阶段：逐期截面回归

这里假设 Beta 已经通过滚动估计得到，并且每条 Beta 记录对应一个资产和一个可用日期。

```python
# rolling_betas:
# columns:
# date, asset, beta_MKT, beta_MOM, beta_LIQ

# 每期的资产收益率与可用 Beta 合并
panel = returns.merge(
    rolling_betas,
    on=["date", "asset"],
    how="inner"
)

gamma_records = []

beta_cols = [
    "beta_MKT",
    "beta_MOM",
    "beta_LIQ"
]

for date, group in panel.groupby("date"):

    group = group.dropna(
        subset=["ret"] + beta_cols
    )

    # 需要足够的截面样本
    if len(group) < 30:
        continue

    X = sm.add_constant(
        group[beta_cols]
    )

    y = group["ret"]

    model = sm.OLS(y, X).fit()

    gamma_records.append({
        "date": date,
        "gamma_0": model.params["const"],
        "gamma_MKT": model.params["beta_MKT"],
        "gamma_MOM": model.params["beta_MOM"],
        "gamma_LIQ": model.params["beta_LIQ"]
    })

gammas = pd.DataFrame(gamma_records)
```

注意：

这里的 `ret` 应该对应 Beta 估计完成之后的未来收益率，而不是与 Beta 形成期重叠的历史收益率。

如果使用无风险利率，应当将因变量替换为超额收益率。

### 11.4 第三阶段：计算平均风险溢价

```python
gamma_cols = [
    "gamma_MKT",
    "gamma_MOM",
    "gamma_LIQ"
]

results = []

for col in gamma_cols:

    series = gammas[col].dropna()

    mean_gamma = series.mean()
    std_gamma = series.std(ddof=1)

    n = len(series)

    se = std_gamma / np.sqrt(n)

    t_stat = mean_gamma / se

    results.append({
        "factor": col,
        "mean_premium": mean_gamma,
        "std": std_gamma,
        "se": se,
        "t_stat": t_stat,
        "n_periods": n
    })

result_df = pd.DataFrame(results)

print(result_df)
```

这段代码实现了基础 Fama-MacBeth 风险价格统计。

需要注意：

这里的普通标准误没有修正 Gamma 序列的自相关。

正式研究可以使用 HAC 标准误。

### 11.5 使用 Newey-West 标准误

```python
from statsmodels.stats.sandwich_covariance import cov_hac

def fama_macbeth_hac(series, maxlags=5):

    y = series.dropna().to_numpy()

    X = np.ones((len(y), 1))

    model = sm.OLS(y, X).fit()

    cov = cov_hac(
        model,
        nlags=maxlags
    )

    mean_premium = model.params[0]

    se = np.sqrt(cov[0, 0])

    t_stat = mean_premium / se

    return {
        "mean_premium": mean_premium,
        "hac_se": se,
        "t_stat": t_stat,
        "n_periods": len(y)
    }
```

这里的 `maxlags` 需要结合数据频率、研究窗口和序列相关结构合理选择，不能机械使用固定值。

另外，Newey-West 只能解决相应的时间序列协方差估计问题，不能自动解决第一阶段 Beta 估计误差、因子遗漏或模型设定错误。

## 结语：我应该如何真正掌握这套知识？

我认为，学习这套体系最重要的不是记住四个模型的公式，而是建立三个层次的理解。

**第一层：经济学层面。**

为什么风险需要补偿？

为什么某些风险可以分散，而某些风险无法分散？

为什么无套利条件能够限制资产的预期收益率？

**第二层：计量经济学层面。**

如何使用 OLS 估计 Beta？

为什么时间序列回归和截面回归解决的是不同问题？

为什么 Beta 与 Gamma 不一样？

为什么必须检验平均风险价格的统计显著性？

**第三层：量化研究层面。**

如何构造因子收益率？

如何避免前视偏差？

如何进行滚动 Beta 估计？

如何使用分组排序与 Fama-MacBeth 交叉验证？

如何判断一个因子具有真实的经济解释能力，而不是仅仅在某段历史数据中表现良好？

最终，我希望能够建立这样一套完整的研究思维：

\[ \boxed{ \begin{aligned} &\text{提出经济学假设}\\ &\downarrow\\ &\text{寻找或构造候选风险因子}\\ &\downarrow\\ &\text{构建因子收益率序列}\\ &\downarrow\\ &\text{估计资产的因子暴露 Beta}\\ &\downarrow\\ &\text{通过截面回归估计风险价格 Gamma}\\ &\downarrow\\ &\text{检验平均风险溢价及其统计显著性}\\ &\downarrow\\ &\text{开展样本外验证与稳健性检验} \end{aligned} } \]

这才是从资产定价理论走向现代量化因子研究的一条完整路径。
