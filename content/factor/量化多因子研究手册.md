## 1. 我如何理解因子

### 1.1 因子不是一个公式，而是一种可检验的描述

我把因子理解为：**对资产某种特征、市场状态、交易行为或风险暴露的定量描述，并且这个描述有可能与未来收益、风险或交易结果存在稳定关系。**

例如，我观察到某些资产在一段时间持续上涨。可以提出一个假设：

> 过去一段时间表现较强的资产，在未来一段时间可能继续表现较强。

这个假设还不是因子。为了研究它，我需要将“表现较强”定义成一个可计算的量。最简单的定义是过去 N 期收益率：

\[
MOM_{i,t}^{(N)} = \frac{P_{i,t}}{P_{i,t-N}} - 1
\]

其中：

- \(i\) 表示资产；
- \(t\) 表示当前时点；
- \(P_{i,t}\) 表示资产在时点 \(t\) 的价格；
- \(N\) 表示回看窗口长度。

计算结果就是一个候选动量因子。它描述过去发生了什么，但不能单凭公式断言未来会发生什么。

我需要把以下概念分开：

| 概念 | 我需要回答的问题 | 示例 |
|---|---|---|
| 市场现象 | 我观察到了什么？ | 某资产持续上涨 |
| 研究假设 | 为什么它可能与未来有关？ | 趋势延续、信息逐步反映 |
| 因子定义 | 如何将现象量化？ | 过去 20 期收益率 |
| 因子实现 | 如何从数据计算？ | `close.pct_change(20)` |
| 因子预处理 | 如何让数据可比较？ | 缩尾、排名、标准化 |
| 因子评价 | 它是否与未来结果有关？ | IC、分组收益、回归 |
| 策略实现 | 如何变成真实交易？ | 仓位、成交、成本、风控 |

如果混淆这些层次，就容易把“能够计算”误认为“有预测价值”，或者把“回测有效”误认为“实盘可执行”。

### 1.2 因子、指标、特征和信号有什么区别？

这些词在不同研究团队中可能有不同用法。我在自己的项目里会采用以下约定，以减少沟通歧义。

- **原始变量**：来自数据源的字段，例如开盘价、收盘价、成交量、成交额。
- **技术指标**：根据价格或成交数据计算出的描述量，例如 ATR、均线、RSI。
- **因子（Factor）**：具有明确研究含义、计划用于解释或预测某个结果的变量。
- **机器学习特征（Feature）**：输入模型的变量。它可以是因子，也可以是其他辅助变量。
- **交易信号（Signal）**：根据因子值、阈值、模型输出或规则形成的交易判断。
- **组合权重（Weight）**：将信号转换为资产配置后的持仓比例。

例如，ATR 首先是一个波幅指标。若我提出“相对波动率可能解释未来风险或收益差异”的假设，并明确构建方法、预测目标和验证流程，就可以将 ATR 的某种变换作为研究因子。

### 1.3 我会用三个维度描述一个因子

每个因子至少需要说明：

1. **经济或行为含义**：我想捕捉什么现象？
2. **计算维度**：它是时序、截面，还是两者结合？
3. **可用时点**：这个数值最早何时能够被我知道？

第三点尤其重要。一个数学表达式即使正确，如果用了当时尚不可获得的数据，研究结果也可能失真。

### 1.4 因子不一定要直接预测收益

我可以构建不同目标的因子：

- 预测未来收益：例如动量、反转、突破延续；
- 预测未来风险：例如波动率、下行风险、尾部风险；
- 预测市场状态：例如区间压缩、趋势强度、波动扩张；
- 预测交易成本：例如流动性、成交额、价格冲击代理；
- 描述风险暴露：例如市场 Beta、行业暴露、规模暴露；
- 作为组合约束或过滤变量：例如资产上市时长、成交活跃度。

这意味着，不应仅以“是否能产生正 IC”判断所有变量的价值。风险、流动性和市场状态变量可能主要用于仓位控制或策略条件判断。

## 2. 我如何从市场现象提出因子假设

我不会先收集一大堆函数，然后随机组合出因子。更合理的方式是先从市场行为或经济机制出发，再选择合适的数学表达式。

### 2.1 从现象到因子的五步法

#### 第一步：描述现象

尽量用可观察、可重复的语言描述，而不是先使用模糊的交易术语。

例如：

- 价格在过去一段时间持续上涨；
- 近期波动区间相对长期区间明显收窄；
- 当前收盘价接近当根 K 线高点；
- 价格突破过去 N 期的最高价；
- 成交量相对于自身历史水平明显放大；
- 短周期趋势与长周期趋势方向一致；
- 价格短期大幅偏离自身历史区间。

#### 第二步：提出可能的机制

例如，突破后可能继续运行的解释包括：

- 新信息逐步进入价格；
- 趋势跟随资金在突破后逐步建立仓位；
- 区间内供需失衡在越过边界后继续扩展；
- 风险预算或仓位约束导致资金分批入场。

反过来，突破也可能是假突破：价格越界后迅速回到区间，原因可能是流动性不足、短期冲击或缺少持续需求。

因此，我不会只提出“突破有效”这一种假设，而会把它拆成更细的问题：

- 突破幅度是否重要？
- 突破前的区间是否足够窄？
- 突破时成交活动是否异常？
- 收盘位置是否接近 K 线高点？
- 突破后是否能持续站在区间之外？
- 不同波动状态下，突破行为是否不同？

#### 第三步：确定量化定义

我会选择能够直接对应假设的变量，而不是随意选一个看起来相关的指标。

例如，若研究“突破幅度”，可以定义：

\[
Breakout_t = \frac{C_t - HH_{t-1,N}}{ATR_{t-1,N}}
\]

其中 \(HH_{t-1,N}\) 是截至上一期的 N 期最高价。分母使用波动尺度，是为了让不同价格水平和不同波动资产之间更容易比较。

如果研究“突破前是否压缩”，可以定义：

\[
Compression_t =
\frac{Range_{short,t-1}}{Range_{long,t-1}}
\]

短期区间相对于长期区间越小，数值越低，代表局部价格活动范围相对收敛。这个解释依赖区间的具体定义，不能直接等同于未来一定会突破。

#### 第四步：确定时间与方向

我需要明确：

- 使用哪个时点的数据？
- 窗口长度是多少？
- 数值越大代表什么？
- 预测的是未来哪一段收益或风险？
- 是否需要做尺度归一化？
- 是否应该按资产自身历史计算，还是与同一时点的其他资产比较？

方向约定尤其容易出错。例如，原始收益率越大通常代表过去涨幅越大；反转因子则可能需要取负号，使较高值代表更强的反转倾向。

#### 第五步：设计可证伪的验证问题

好的研究假设应该允许被数据否定。

例如：

> 在相同预测期内，突破幅度更大的资产，未来收益是否具有更高的均值或更高的正收益概率？

这个问题比“突破因子是不是有效”更明确。

后续可以使用 IC、分位数组合、条件分组和样本外测试验证。若结果不稳定，我会检查定义、样本范围、交易成本、市场状态和数据质量，而不是不断调整参数直到得到理想结果。

### 2.2 我会给每个因子建立研究卡片

建议每个因子至少记录以下字段：

| 字段 | 内容 |
|---|---|
| 因子名称 | `breakout_strength_20` |
| 研究类别 | 价格结构 / 突破 |
| 研究假设 | 越强的有效突破可能对应更强的后续趋势 |
| 原始输入 | OHLCV |
| 数学定义 | 收盘价相对历史区间上沿的波动率归一化距离 |
| 窗口 | 20 期 |
| 计算时点 | 当前 K 线收盘后 |
| 数据频率 | 日线或其他指定频率 |
| 方向约定 | 越高表示突破幅度越大 |
| 缺失值规则 | 历史窗口不足时保留 NaN |
| 预处理 | 按研究设计决定是否缩尾、标准化 |
| 潜在风险 | 假突破、极端行情、交易成本、窗口敏感性 |
| 版本 | `v1` |
| 研究状态 | 待计算 / 待验证 / 已验证 / 已弃用 |

这张卡片能让我区分因子的研究逻辑与代码实现，也能避免后期忘记某个因子最初想表达什么。

## 3. 因子构建的主要研究视角

本章是整份手册的核心。我会从不同角度观察市场，并将每个角度转化成候选因子。每一类都包含研究问题、数学思路、示例和局限。

### 3.1 价格方向：趋势、动量与反转

#### 我想研究什么？

我首先观察价格的方向性变化：

- 过去一段时间是否上涨或下跌？
- 趋势是否持续？
- 短期趋势是否强于长期趋势？
- 近期上涨是否已经过度？
- 过去的涨跌是否可能在未来延续或反转？

#### 常用构建方式

**N 期累计收益率：**

\[
MOM_{N,t}=\frac{C_t}{C_{t-N}}-1
\]

**跳过最近一期的动量：**

\[
MOM^{skip}_{N,t}=\frac{C_{t-1}}{C_{t-N-1}}-1
\]

跳过最近一期的动量常用于研究中期趋势，避免最近一期短期反转或微观噪声影响。但是否应该跳过最近一期，需要根据市场和预测期限决定。

**短长周期动量差：**

\[
MOMSpread_t=MOM_{short,t}-MOM_{long,t}
\]

它描述不同期限累计收益的差异，但并非严格的趋势加速度。若需要衡量增长速度变化，可以比较单位时间收益、回归斜率或收益率的变化。

**滚动正收益比例：**

\[
UpRatio_{N,t}=
\frac{\sum_{k=0}^{N-1} I(R_{t-k}>0)}
{\text{有效观测数}}
\]

它描述过去窗口中上涨期的占比，不考虑每次涨跌幅度。

#### 我会注意什么？

- 不同动量窗口可能捕捉不同机制；
- 价格动量与收益动量不是完全相同的研究对象；
- 短期反转和中期趋势可能同时存在；
- 不同市场状态下，趋势延续性可能发生变化；
- 不应把多个高度相似的动量窗口当作多个独立证据。

### 3.2 价格相对位置：区间、极值与偏离

#### 我想研究什么？

价格在自身历史范围内处于什么位置？它接近区间顶部、底部，还是已经离开原有区间？

#### 常见定义

**历史区间位置：**

\[
Pos_{N,t}=
\frac{C_t-LL_{N,t-1}}{HH_{N,t-1}-LL_{N,t-1}}
\]

其中历史高低点只使用当前期之前的数据。位置值可以低于 0 或高于 1，分别表示价格跌出历史区间下沿或突破上沿。

**归一化突破幅度：**

\[
Breakout_{N,t}=
\frac{C_t-HH_{N,t-1}}{ATR_{N,t-1}}
\]

**距离历史高点：**

\[
DistHigh_{N,t}=\frac{C_t}{HH_{N,t-1}}-1
\]

**距离历史低点：**

\[
DistLow_{N,t}=\frac{C_t}{LL_{N,t-1}}-1
\]

#### 研究解释

- 区间位置高，可能表示价格接近历史高位，也可能表示趋势较强；
- 区间位置低，可能表示价格接近历史低位，也可能表示下跌趋势持续；
- 跌出或突破历史区间，可以用来描述价格结构发生变化；
- 同一个位置因子可能同时包含趋势和均值回归信息。

因此，我会把“价格处于高位”与“价格即将反转”分成两个假设，不会直接把高位等同于卖出信号。

### 3.3 波动与风险：幅度、扩张、压缩和尾部

#### 我想研究什么？

我关注价格变化有多剧烈，以及波动状态如何变化：

- 资产近期是否比过去更不稳定？
- 波动是否持续扩张？
- 价格区间是否收窄？
- 下跌风险是否高于上涨风险？
- 极端收益是否频繁发生？

#### 常见构建方式

**历史波动率：**

\[
Vol_{N,t}=Std(R_{t-N+1},\ldots,R_t)
\]

**波动率变化比：**

\[
VolRatio_t=\frac{Vol_{short,t}}{Vol_{long,t}}
\]

若分母可能为零，应明确处理规则；也可以使用带稳定项的比值，但稳定项的量纲必须合理。

**相对振幅：**

\[
RangePct_t=\frac{H_t-L_t}{C_t}
\]

**历史区间宽度：**

\[
RangeWidth_{N,t}=\frac{HH_{N,t}-LL_{N,t}}{C_t}
\]

**下行半方差：**

\[
DownVar_{N,t}=
\frac{1}{N}\sum_{k=0}^{N-1}
\min(R_{t-k},0)^2
\]

这里使用固定分母 N，便于在窗口间保持定义一致；若只对负收益观测求平均，则得到的是另一种统计量，需要明确区分。

#### 我会注意什么？

波动因子不一定具有单一方向的收益预测关系。高波动可能意味着更大的机会，也可能意味着更高的交易成本和尾部风险。因此，波动因子常常既可作为研究变量，也可作为仓位调整或风险控制变量。

### 3.4 成交量、成交额与市场参与程度

#### 我想研究什么？

成交活动反映了市场参与程度，但成交量本身不能直接解释为资金净流入。

我会关注：

- 当前成交量相对于自身历史是否异常；
- 价格上涨是否伴随成交活动增强；
- 成交活动是否与价格变化同步；
- 成交额相对于价格波动的关系；
- 成交活动是否集中在极端行情中。

#### 常见构建方式

**相对成交量：**

\[
RelVol_{N,t}=\frac{V_t}{MA_N(V)_t}
\]

**对数成交量：**

\[
LogVol_t=\log(1+V_t)
\]

**成交量标准分：**

\[
VolZ_{N,t}=
\frac{V_t-\mu_{V,N,t}}{\sigma_{V,N,t}}
\]

**量价交互：**

\[
PV_t=R_t\cdot \log(1+V_t)
\]

**收益与成交量相关性：**

\[
CorrPV_{N,t}=Corr(R,V,N)
\]

#### 我会注意什么？

- 原始成交量通常有明显的偏态分布；
- 不同资产之间的成交量单位和规模可能完全不同；
- 不同交易所的成交量统计口径可能不同；
- 价格上涨与成交量放大不代表资金净流入；
- 相关性只能描述共同变化，不能单独证明因果。

对于加密货币，我还会特别检查现货成交量、合约成交量、不同交易所成交量之间的可比性。

### 3.5 K 线内部结构与价格行为

我不一定需要先计算复杂的技术指标。OHLC 四个字段本身就可以形成很多结构特征。

定义当根 K 线振幅：

\[
Range_t=H_t-L_t
\]

**实体比例：**

\[
BodyRatio_t=\frac{|C_t-O_t|}{H_t-L_t}
\]

**收盘位置：**

\[
CLV_t=\frac{2C_t-H_t-L_t}{H_t-L_t}
\]

**上影线比例：**

\[
UpperWick_t=
\frac{H_t-\max(O_t,C_t)}{H_t-L_t}
\]

**下影线比例：**

\[
LowerWick_t=
\frac{\min(O_t,C_t)-L_t}{H_t-L_t}
\]

当振幅为零时，这些比例没有定义，应保留 NaN 或按明确规则处理，不能直接除以零。

#### 我会怎样扩展？

单根 K 线结构可以进一步形成：

- 过去 N 期收盘位置的均值；
- 上影线比例连续超过阈值的比例；
- 大实体 K 线出现频率；
- K 线方向连续性；
- 突破前的平均实体与平均振幅；
- 突破后的收盘位置变化；
- 上下影线结构与成交活动的交互项。

这些特征能够将价格行为转成结构化变量，但其含义仍然需要验证。上影线可能来自卖压，也可能来自流动性不足、短期价格冲击或交易时段效应。

### 3.6 趋势持续性与路径结构

累计收益只告诉我起点和终点的差异，却不描述中间路径。

例如，两条价格路径可能具有相同的 20 期收益：一条平稳上涨，另一条先大幅上涨再回撤。它们的风险和可交易性可能不同。

因此，我会研究：

- 正收益期占比；
- 收益方向连续性；
- 最大回撤；
- 上涨与下跌幅度之比；
- 价格路径的单调程度；
- 趋势过程中回撤的深度与频率；
- 趋势收益相对于总波动的比值。

一种简单的路径效率指标是：

\[
EfficiencyRatio_{N,t}=
\frac{|C_t-C_{t-N}|}
{\sum_{k=0}^{N-1}|C_{t-k}-C_{t-k-1}|}
\]

当分母非零时，该比值通常介于 0 和 1 之间。越接近 1，表示净价格位移相对于路径总变动越大；越接近 0，表示路径中的来回波动较多。

这类指标描述路径结构，不应直接被解释成未来收益预测能力。

### 3.7 流动性与价格冲击代理

若研究目标包含实际交易，我会考虑交易成本和流动性，而不仅是收益预测。

在缺乏买卖盘数据时，可以构造一些粗略代理：

- 成交额水平；
- 成交额的时间序列变化；
- 绝对收益相对于成交额的比例；
- 大幅价格变动发生时的成交活动；
- 价格振幅相对于成交额的比值。

例如：

\[
ImpactProxy_t=\frac{|R_t|}{Amount_t}
\]

这个指标只是粗略代理，受到成交额单位、资产价格、波动率和数据质量影响。它不是严格的市场冲击估计，也不能替代买卖价差、盘口深度和真实成交滑点数据。

### 3.8 多周期关系

我不会只把不同周期的指标堆在一起，而会关注周期之间的关系：

- 短期方向与长期方向是否一致；
- 短期波动相对长期波动是否扩张；
- 短期区间相对长期区间是否压缩；
- 长周期趋势中的短周期回撤有多深；
- 长周期趋势是否正在加速或衰减。

例如：

\[
TrendAgreement_t =
\frac{1}{K}\sum_{k=1}^{K} sign(MOM_{N_k,t})
\]

这个值反映多个周期方向的一致程度。若多个周期的动量方向一致，绝对值会更大；但各周期之间并不独立，不能把一致性当作多个独立证据的简单累加。

### 3.9 交互因子与条件因子

我会先理解单个变量，再考虑交互。交互项的目的不是增加因子数量，而是表达“一个特征的作用可能取决于另一个特征”。

例如：

\[
F_t=MOM_t\cdot \log(1+RelVol_t)
\]

它表达动量与相对成交量的联合变化。

也可以研究条件效应：

- 仅在波动率扩张时观察突破因子；
- 分别研究高波动与低波动环境下的动量；
- 在长期趋势向上时研究短期反转；
- 在成交活动异常时研究价格冲击。

条件研究能帮助我识别因子的适用环境，但也增加了样本切分和多重检验问题。切分越多，越容易偶然发现看似显著的结果。

### 3.10 基本面、规模与风险暴露因子

若数据不局限于 OHLCV，我还可以构建：

- 市值或规模因子；
- 估值因子；
- 盈利能力与质量因子；
- 杠杆与财务风险因子；
- 行业和风格暴露；
- 市场 Beta；
- 流动性与交易成本因子。

这类因子对数据质量和历史可用时间要求更高。例如，财务数据必须按真实披露时间对齐，而不能简单按报告期末日期回填。规模和行业数据也需要保证历史时点一致，避免使用后来修订的数据污染历史研究。

## 4. 从研究假设到可计算因子的完整流程

我会把每个因子构建任务拆成以下步骤。

### 4.1 明确研究对象

先确定：

- 资产范围；
- 数据频率；
- 原始字段；
- 计算时点；
- 目标用途；
- 是否需要跨资产比较。

例如，我研究加密资产日线动量，资产范围可能是满足上市时间和数据质量要求的现货交易对，输入字段是日线收盘价，计算频率为每日一次。

### 4.2 明确公式与边界条件

公式不完整时，代码就容易产生歧义。

以区间位置为例，我需要规定：

- 历史窗口是否包含当前 K 线；
- 最高价与最低价是否来自同一窗口；
- 区间宽度为零时怎么办；
- 历史数据不足时是否输出 NaN；
- 价格异常时如何处理。

### 4.3 先写一个可读的正确版本

我优先保证逻辑正确、索引对齐和边界条件明确，再考虑优化速度。过早优化会增加调试难度。

### 4.4 用小样本验证

我会挑选少量资产、少量日期，手工核对：

- 当前因子是否只使用历史可用数据；
- 滚动窗口边界是否正确；
- 计算结果是否与公式一致；
- 分组前后索引是否改变；
- 缺失值是否符合预期。

### 4.5 批量计算并记录元数据

每个因子至少保存：

- 名称；
- 版本；
- 公式或代码版本；
- 输入字段；
- 窗口参数；
- 计算时间；
- 数据版本；
- 缺失值比例；
- 输出类型。

这样才能在后续研究中重现同一份因子数据。

```python
df = df.sort_values(["asset", "date"]).copy()

```

**时序运算：** 同一资产沿时间计算。

```python
df["ret_20"] = (
```

```python
df["ret_20_rank"] = (
```

我会优先选择返回索引清晰、容易验证的写法。尤其是多资产时序计算，必须避免不同资产的窗口相互污染。

## 7. 时序函数与滚动窗口

### 7.1 `rolling()` 的关键参数

```python
series.rolling(
    window=20,
    min_periods=20,
    center=False,
).mean()
```

- `window`：窗口长度；
- `min_periods`：最少有效观测数；
- `center=False`：默认窗口以当前行作为右端点，适合常规历史特征；
- `center=True`：会使用当前点两侧的数据，不适合直接作为历史预测因子；
- `closed`：用于部分时间索引窗口的边界控制。

我会根据因子定义决定 `min_periods`。窗口不足时直接保留 NaN，通常比无条件填充 0 更安全。

### 7.2 常见滚动统计

| 函数 | 含义 | 用途 |
|---|---|---|
| `mean()` | 均值 | 近期水平 |
| `sum()` | 总和 | 累计成交量 |
| `std()` | 标准差 | 波动 |
| `var()` | 方差 | 风险程度 |
| `min()` / `max()` | 极值 | 区间边界 |
| `median()` | 中位数 | 鲁棒中心 |
| `quantile(q)` | 分位数 | 尾部和阈值 |
| `skew()` | 偏度 | 分布不对称性 |
| `kurt()` | 超额峰度 | 尾部形态 |
| `corr()` | 相关性 | 两变量共同变化 |
| `cov()` | 协方差 | 联合变动幅度 |
| `apply(func)` | 自定义计算 | 回归斜率、特殊统计 |

pandas 的 `rolling().std()` 默认使用 `ddof=1`。如果希望使用总体标准差，需要明确设置 `ddof=0`。短窗口的偏度、峰度和相关性估计可能很不稳定，应谨慎使用。

### 7.3 `shift`、`diff` 与 `pct_change`

```python
g = df.groupby("asset")["close"]

df["close_lag_1"] = g.shift(1)
df["price_diff_1"] = g.diff(1)
df["ret_1"] = g.pct_change(1, fill_method=None)
df["ret_5"] = g.pct_change(5, fill_method=None)
```

- `shift` 获取历史值；
- `diff` 计算绝对变化；
- `pct_change` 计算相对变化。

面板数据中应使用分组运算，避免不同资产之间出现跨组差分。

### 7.4 `ewm()` 指数加权统计

指数加权均值为近期数据赋予更高权重：

\[
EMA_t=\alpha X_t+(1-\alpha)EMA_{t-1}
\]

```python
df["ema_20"] = (
    df.groupby("asset")["close"]
      .transform(
          lambda s: s.ewm(
              span=20,
              adjust=False,
              min_periods=20,
          ).mean()
      )
)
```

指数加权可以更快响应近期变化，但并不消除滞后，也不天然优于简单滚动统计。

### 7.5 滚动斜率

对数价格回归斜率可用来描述价格的相对增长速度：

```python
def log_price_slope(x):
    x = np.asarray(x, dtype=float)

    if not np.isfinite(x).all() or np.any(x <= 0):
        return np.nan

    t = np.arange(len(x), dtype=float)
    return np.polyfit(t, np.log(x), 1)[0]
```

```python
df["log_slope_20"] = (
    df.groupby("asset")["close"]
      .transform(
          lambda s: s.rolling(20, min_periods=20)
                    .apply(log_price_slope, raw=True)
      )
)
```

这是易读的参考实现。大规模计算时，逐窗口调用 `np.polyfit` 可能很慢，可改为闭式公式、Numba 或专门的批量计算方法。

## 8. 截面算子与因子预处理

### 8.1 截面排名

```python
df["factor_rank"] = (
    df.groupby("date")["factor"]
      .rank(pct=True, method="average")
)
```

排名适合比较资产的相对位置、构造分位数组合和降低原始尺度差异。它不会自动消除全部异常值，也会丢失原始数值距离信息。

### 8.2 截面 Z-score

\[
Z_{i,t}=\frac{F_{i,t}-\mu_t}{\sigma_t}
\]

```python
def cross_sectional_zscore(s):
    std = s.std(ddof=0)

    if not np.isfinite(std) or std == 0:
        return pd.Series(np.nan, index=s.index)

    return (s - s.mean()) / std

df["factor_zscore"] = (
    df.groupby("date")["factor"]
      .transform(cross_sectional_zscore)
)
```

Z-score 适合需要保留相对距离信息的模型或因子合成，但对极端值较敏感。常见做法是先进行适当的异常值处理，再标准化。

### 8.3 分位数分组

```python
def cross_sectional_bucket(s, q=5):
    valid = s.notna()
    out = pd.Series(np.nan, index=s.index, dtype=float)

    if valid.sum() < q:
        return out

    ranks = s.loc[valid].rank(method="first")

    out.loc[valid] = pd.qcut(
        ranks,
        q=q,
        labels=False,
    )

    return out
```

先排名再分组可以减少因大量重复值导致的分箱失败，但 `method="first"` 会按观测顺序打破并列关系。对于离散因子，需要检查分组是否具有合理的经济含义。

### 8.4 缩尾

```python
def winsorize_series(s, lower=0.01, upper=0.99):
    valid = s.notna()

    if not valid.any():
        return s.copy()

    lo = s.loc[valid].quantile(lower)
    hi = s.loc[valid].quantile(upper)

    return s.clip(lower=lo, upper=hi)

df["factor_winsor"] = (
    df.groupby("date")["factor"]
      .transform(winsorize_series)
)
```

缩尾会改变极端值的数值，但保留对应观测。是否缩尾、采用什么分位数，应由研究设计决定，而不是默认每个因子都需要缩尾。

### 8.5 MAD 鲁棒标准化

\[
Z^{robust}_{i,t}=
\frac{F_{i,t}-Median_t(F)}
{1.4826 \cdot MAD_t(F)}
\]

其中：

\[
MAD_t(F)=Median_t(|F-Median_t(F)|)
\]

```python
def robust_zscore(s):
    med = s.median()
    mad = (s - med).abs().median()

    if not np.isfinite(mad) or mad == 0:
        return pd.Series(np.nan, index=s.index)

    return (s - med) / (1.4826 * mad)
```

MAD 对极端值比标准差更稳健。常数 1.4826 是正态分布下的尺度转换系数，不意味着任意分布下都能得到与标准差完全等价的结果。

## 9. 量价因子公式库

本章把前述思路组合成可复用的公式。以下是研究候选，不是推荐直接交易的信号。

### 9.1 动量与反转

| 因子 | 公式 | 含义 |
|---|---|---|
| N 期动量 | \(C_t/C_{t-N}-1\) | 历史累计收益 |
| 跳过最近一期的动量 | \(C_{t-1}/C_{t-N-1}-1\) | 排除最近一期变化 |
| N 期反转 | \(-MOM_{N,t}\) | 与历史收益反向 |
| 动量差 | \(MOM_{short}-MOM_{long}\) | 不同期限的收益差异 |
| 正收益比例 | 窗口正收益次数 / 有效期数 | 上涨频率 |
| 对数价格斜率 | 对窗口内 log(price) 做线性回归 | 趋势速度代理 |

```python
g = df.groupby("asset")["close"]

df["mom_20"] = g.pct_change(20, fill_method=None)
df["mom_20_skip_1"] = g.shift(1) / g.shift(21) - 1
df["reversal_5"] = -g.pct_change(5, fill_method=None)
```

### 9.2 波动与区间

真实波幅定义为：

\[
TR_t=\max(H_t-L_t, |H_t-C_{t-1}|, |L_t-C_{t-1}|)
\]

```python
prev_close = df.groupby("asset")["close"].shift(1)

tr = pd.concat(
    [
        df["high"] - df["low"],
        (df["high"] - prev_close).abs(),
        (df["low"] - prev_close).abs(),
    ],
    axis=1,
).max(axis=1)

df["tr"] = tr

df["atr_20"] = (
    df.groupby("asset")["tr"]
      .transform(lambda s: s.rolling(20, min_periods=20).mean())
)

df["atr_pct"] = df["atr_20"] / df["close"]
```

这使用简单移动平均版本的 ATR；经典 Wilder ATR 使用不同平滑方式。研究时要固定定义，不要将两种实现混为一谈。

### 9.3 历史区间与突破

```python
g = df.groupby("asset")

df["prior_high_20"] = g["high"].transform(
    lambda s: s.shift(1).rolling(20, min_periods=20).max()
)

df["prior_low_20"] = g["low"].transform(
    lambda s: s.shift(1).rolling(20, min_periods=20).min()
)

width = df["prior_high_20"] - df["prior_low_20"]

df["range_position_20"] = (
    (df["close"] - df["prior_low_20"])
    / width.where(width > 0)
)

df["breakout_strength_20"] = (
    (df["close"] - df["prior_high_20"])
    / df["atr_20"]
)
```

当前收盘价可以用于收盘后生成的因子，但历史突破基准必须排除当前 K 线。若目标是在当前 K 线开始前产生信号，当前 K 线的收盘价也不能使用。

### 9.4 成交量与量价交互

```python
g = df.groupby("asset")

df["volume_ma_20"] = g["volume"].transform(
    lambda s: s.rolling(20, min_periods=20).mean()
)

df["relative_volume_20"] = (
    df["volume"] / df["volume_ma_20"].replace(0, np.nan)
)

df["log_volume"] = np.log1p(df["volume"])

df["ret_1"] = g["close"].pct_change(fill_method=None)

df["price_volume_interaction"] = (
    df["ret_1"] * np.log1p(df["relative_volume_20"].clip(lower=0))
)
```

这是一个简单交互特征。成交量异常值、负值、零值以及数据口径必须先检查；不同市场的数据字段不一定能直接比较。

### 9.5 K 线结构

```python
bar_range = (df["high"] - df["low"]).replace(0, np.nan)

df["body_ratio"] = (
    (df["close"] - df["open"]).abs() / bar_range
)

df["upper_wick_ratio"] = (
    (df["high"] - df[["open", "close"]].max(axis=1))
    / bar_range
)

df["lower_wick_ratio"] = (
    (df[["open", "close"]].min(axis=1) - df["low"])
    / bar_range
)

df["close_location"] = (
    (2 * df["close"] - df["high"] - df["low"])
    / bar_range
)
```

这类因子适合与区间、趋势、成交活动结合研究，但不应把某种 K 线形态直接解释为确定的买卖力量。

## 10. 非线性、交互项与状态条件因子

### 10.1 常见非线性变换

| 变换 | 示例 | 可能用途 |
|---|---|---|
| 绝对值 | `abs(x)` | 强度而非方向 |
| 平方 | `x ** 2` | 强调大幅偏离 |
| 符号 | `sign(x)` | 只保留方向 |
| 对数 | `log1p(x)` | 压缩右偏分布 |
| 截断 | `clip(x, lo, hi)` | 限制极端数值 |
| 分段 | `where(x > threshold, ...)` | 表达阈值效应 |
| 标准化偏离 | `(x - rolling_mean) / rolling_std` | 当前值相对自身历史的异常程度 |

非线性变换应当有明确动机。例如，平方会丢失方向信息；绝对值也会把上涨和下跌映射为相同的强度。它们并不是可以任意替换的通用增强工具。

### 10.2 交互项

交互项用于表达一个特征的作用可能依赖另一个特征。

例如：

\[
F_t=MOM_t \times \log(1+RelVol_t)
\]

或者：

\[
F_t=Breakout_t \times (1-Compression_t)
\]

第二个表达式只有在 `Compression` 的定义和取值范围明确时才有解释意义。若压缩指标不在 0 到 1 之间，表达式的尺度和方向可能与预期不同。

### 10.3 条件因子

我可以先定义一个市场状态变量，再研究某个因子在不同状态下的表现：

```python
df["high_vol_state"] = (
    df["vol_20"] > df["vol_60"]
)

df["momentum_in_high_vol"] = (
    df["mom_20"].where(df["high_vol_state"])
)
```

这里 `where()` 将不满足条件的值设为缺失。这种处理适合分状态分析，但如果后续模型不能处理缺失值，必须明确后续处理规则。

条件研究需要注意样本量：当我把样本切成很多状态和子组后，每个组的观测可能变少，估计结果也会更不稳定。

## 11. 风险中性化与回归工具

### 11.1 OLS 的基本形式

\[
F=X\beta+\epsilon
\]

其中 \(F\) 是待处理因子，\(X\) 是市值、行业哑变量或其他控制变量，\(\epsilon\) 是无法被该线性模型解释的残差。

中性化残差只表示剥离了指定控制变量的线性解释部分，不意味着已经消除了所有风险，也不保证预测能力提高。

### 11.2 每日截面中性化模板

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm


def neutralize_one_day(group):
    y = group["factor"]

    X = group[["log_cap"]].copy()
    industry = pd.get_dummies(
        group["industry"],
        prefix="industry",
        dtype=float,
    )

    X = pd.concat([X, industry], axis=1)
    X = sm.add_constant(X, has_constant="add")

    valid = y.notna() & X.notna().all(axis=1)

    result = pd.Series(np.nan, index=group.index, dtype=float)

    if valid.sum() <= X.shape[1]:
        return result

    Xv = X.loc[valid]
    yv = y.loc[valid]

    # 删除无变异列；常数项保留
    nonconstant = Xv.nunique(dropna=False) > 1
    if "const" in nonconstant.index:
        nonconstant.loc["const"] = True

    Xv = Xv.loc[:, nonconstant]

    # 若矩阵仍然秩亏，生产环境应进一步处理共线性
    fit = sm.OLS(yv, Xv).fit()
    result.loc[valid] = fit.resid

    return result


df["factor_neutral"] = (
    df.groupby("date", group_keys=False)
      .apply(neutralize_one_day)
      .reindex(df.index)
)
```

这是教学模板，不是对所有数据集都稳健的生产级中性化引擎。正式实现时，我还会检查样本量、设计矩阵秩、行业类别、共线性、缺失值和索引对齐。

### 11.3 Beta 与残差动量

市场 Beta 的常见定义：

\[
\beta_i=\frac{Cov(R_i,R_m)}{Var(R_m)}
\]

```python
# 单资产或已对齐的一组时序数据
beta_60 = (
    asset_return.rolling(60).cov(market_return)
    / market_return.rolling(60).var()
)
```

批量面板计算时，需要确保资产收益与市场收益在同一时间索引上对齐，并且每个资产使用自己的历史窗口。

残差动量通常先通过时序回归剥离市场或其他风险因子，再研究残差收益的持续性。回归参数必须仅使用当时可获得的数据估计，不能用全样本参数回头计算历史预测因子。

### 11.4 Fama–MacBeth 回归

第一步，对每个时点执行截面回归：

\[
R_{i,t+1}=\gamma_{0,t}+\gamma_t^\top F_{i,t}+\epsilon_{i,t+1}
\]

第二步，分析各期回归系数的时间序列均值和统计显著性：

\[
\bar{\gamma}=\frac{1}{T}\sum_{t=1}^{T}\gamma_t
\]

Fama–MacBeth 与 IC 检验不同。IC 衡量因子和未来收益之间的相关关系；Fama–MacBeth 通过截面回归估计控制其他变量后的因子收益。若系数存在自相关，需要使用合适的标准误估计方法。

## 12. 因子评价接口：为后续研究预留规范

即使当前任务只构建因子，我也会从一开始就保证因子数据可以与未来收益正确对齐。

### 12.1 预测目标必须明确

我会区分：

- 下一期收益；
- 未来 N 期累计收益；
- 未来 N 期波动率；
- 未来最大回撤；
- 未来正收益概率；
- 交易成本或流动性结果。

这些目标不应混为一谈。

例如，未来 N 期累计收益可以定义为：

\[
R_{t,t+N}=\frac{C_{t+N}}{C_t}-1
\]

如果因子在 t 日收盘后才可用，交易是否能以 \(C_t\) 成交必须由实际交易机制决定。研究时不能默认因子生成价就是可成交价。

### 12.2 IC 的基础接口

```python
from scipy.stats import pearsonr, spearmanr


def calc_cross_sectional_ic(group, factor_col, target_col):
    valid = group[[factor_col, target_col]].dropna()

    if len(valid) < 3:
        return pd.Series({
            "pearson_ic": np.nan,
            "spearman_ic": np.nan,
            "n": len(valid),
        })

    return pd.Series({
        "pearson_ic": pearsonr(
            valid[factor_col],
            valid[target_col],
        ).statistic,
        "spearman_ic": spearmanr(
            valid[factor_col],
            valid[target_col],
        ).statistic,
        "n": len(valid),
    })
```

该函数只演示单个截面的计算接口。正式使用时还需要定义目标收益的构建方式、最小样本量、并列值处理和异常值策略。

### 12.3 评价指标不能替代研究设计

- IC 均值描述平均相关性；
- IC 标准差描述时间波动；
- ICIR 描述 IC 均值相对于其波动的大小；
- 分组收益描述因子排序的收益差异；
- 换手率和交易成本用于判断可执行性；
- 样本外检验用于降低过拟合风险。

不能只因为某个因子的历史 IC 较高，就认定它一定能产生可交易的超额收益。

## 13. 多周期因子与跨周期信息

### 13.1 多周期不是简单堆叠

我会区分三个问题：

1. 不同周期的特征是否提供重复信息？
2. 不同周期之间的差异是否包含新的信息？
3. 跨周期特征在交易时点是否真正可用？

常见多周期特征：

| 因子 | 构建思路 |
|---|---|
| 趋势方向一致性 | 多个周期动量符号的平均 |
| 短长周期动量差 | 短周期收益与长周期收益之差 |
| 波动率扩张 | 短周期波动率相对长周期波动率的比值 |
| 区间压缩 | 短周期区间宽度 / 长周期区间宽度 |
| 趋势回撤 | 当前价格相对长周期极值的位置 |
| 突破与长期趋势交互 | 突破幅度乘以长期趋势方向或强度 |

### 13.2 不同频率的数据必须按可用时点合并

例如，我在 1 小时策略中使用 1 日线因子。当天的日线收盘价只有在日线结束后才最终确定，不能提前填入当天早些时候的小时数据。

正确的做法是根据实际时区和 K 线结束时间，将已完成的高周期数据向后对齐到可用时点。简单地按日期合并，可能把尚未完成的日线数据泄漏到日内样本。

### 13.3 跨周期合并的检查

我会逐项确认：

- 时间戳表示 K 线开始还是结束；
- 交易所时区与本地时区是否一致；
- 高周期 K 线是否已经结束；
- 缺失的高周期数据如何处理；
- 合并是否产生重复行；
- 是否存在向未来填充的情况。

## 14. 因子数据工程与存储规范

### 14.1 统一索引

对于多资产因子研究，我通常会将索引定义为：

`(date, asset)`

每一行代表一个资产在一个时点的观测，每个因子对应一列。

例如：

| date | asset | mom_20 | vol_20 | range_position_20 |
|---|---|---:|---:|---:|
| 2026-01-01 | AAA | NaN | NaN | NaN |
| 2026-01-02 | AAA | 0.02 | 0.01 | 0.73 |
| 2026-01-01 | BBB | NaN | NaN | NaN |

### 14.2 因子列命名

我会让名称直接表达计算含义，例如：

- `mom_20`
- `mom_20_skip_1`
- `vol_20`
- `atr_pct_20`
- `range_position_20`
- `breakout_strength_20`
- `relative_volume_20`
- `close_location`
- `factor_neutral`

避免使用 `factor1`、`new_factor` 这类无法追溯定义的名称。

### 14.3 Parquet 的角色

Parquet 适合存储列式、结构化的因子数据。它可以与 pandas、PyArrow、DuckDB 等工具配合使用。

我会考虑：

- 按日期或日期区间分区；
- 明确字段类型；
- 保持索引语义稳定；
- 记录数据版本和计算版本；
- 避免每次研究都重复计算所有历史因子；
- 使用 DuckDB 或其他查询引擎按需读取列和分区。

如果原始行情数据采用特定的二元索引或多重索引格式，我会先确认其真实含义，再决定因子数据是保留相同索引、保存为普通列，还是采用分区文件布局。关键是让后续研究能无歧义地对齐数据。

### 14.4 可复现性

每次因子数据构建至少应记录：

- 代码版本；
- 输入数据版本；
- 计算时间；
- 因子定义版本；
- 参数配置；
- 输出文件路径；
- 行数与唯一键检查结果；
- 缺失值比例；
- 关键字段的最小值、最大值和分位数。

这样在以后修改因子定义时，我可以明确区分不同版本的结果，而不是覆盖后无法还原。

## 15. Qlib、聚宽、米筐与 pandas 的关系

这些工具的设计目标和 API 不完全相同。我会优先统一研究逻辑，再适配各个平台。

| 任务 | pandas / NumPy | Qlib | 聚宽 / 米筐 |
|---|---|---|---|
| 时序滚动统计 | `rolling()` | 表达式算子 | 平台接口或自定义计算 |
| 收益率 | `pct_change()` | 表达式算子 | 行情序列运算 |
| 截面排名 | `groupby(date).rank()` | 根据表达式与处理器语义实现 | 平台 API 或自定义 |
| 标准化 | `transform()` | 处理器或自定义流程 | 预处理 API 或自定义 |
| 中性化 | statsmodels OLS | 处理器或自定义流程 | 平台接口或自定义回归 |
| 批量因子计算 | pandas / NumPy | Expression 引擎 | 平台研究接口 |

Qlib 表达式有自身的算子语法和计算语义，例如 `$close` 及滚动算子。具体支持的函数应以所使用版本的官方文档为准，不能直接假设所有 pandas 方法都能写进表达式。

聚宽与米筐也可能因版本、权限和接口不同而有所差异。对可复用因子研究而言，我更重视统一输入输出格式、索引、命名和缺失值约定，而不是强求不同平台的代码完全一致。

## 16. 常见错误与防前视检查清单

### 16.1 数据和索引错误

- [ ] `(date, asset)` 是否唯一？
- [ ] 是否按资产和时间正确排序？
- [ ] 是否有跨资产滚动或差分？
- [ ] 是否有重复行情或异常时间戳？
- [ ] 是否明确处理缺失值和无穷值？
- [ ] 不同交易所、不同资产的数据字段是否可比？

### 16.2 时间与前视偏差

- [ ] 因子是否只使用计算时点已知的数据？
- [ ] 突破区间是否排除了当前 K 线？
- [ ] 高周期数据是否已经完成？
- [ ] 是否使用了全样本均值、标准差或回归系数处理历史数据？
- [ ] 财务或基本面数据是否按实际发布时间对齐？
- [ ] 未来收益是否与因子时间严格错开？
- [ ] 回测成交价是否在实际机制下可执行？

### 16.3 因子定义错误

- [ ] 因子值越大代表什么，是否写清楚？
- [ ] 是否把价格变化量与收益率混淆？
- [ ] 是否把相关性误当成因果？
- [ ] 是否将相似窗口的重复因子当作独立信息？
- [ ] 是否有合理的经济或行为解释？
- [ ] 参数选择是否经过过多尝试？

### 16.4 预处理错误

- [ ] 是否机械地对所有因子缩尾？
- [ ] 是否把缺失值直接填成零？
- [ ] 是否明确截面排名和时序排名的区别？
- [ ] 中性化是否按研究目标设计？
- [ ] 是否检查中性化回归的样本量与矩阵秩？
- [ ] 是否记录预处理前后的数据分布？

### 16.5 工程错误

- [ ] 因子函数是否可重复执行？
- [ ] 输出是否与原始索引严格对齐？
- [ ] 是否保存因子定义和版本信息？
- [ ] 是否检查输出行数和唯一键？
- [ ] 是否有小样本单元测试？
- [ ] 是否记录缺失值比例和异常统计？

## 17. 我建议建立的因子函数库

下面给出一个精简、可复用的起点。它不试图一次覆盖所有因子，而是先提供几种基础构建模式。

```python
from __future__ import annotations

import numpy as np
import pandas as pd


def add_momentum_features(
    df: pd.DataFrame,
    asset_col: str = "asset",
    close_col: str = "close",
    windows: tuple[int, ...] = (5, 20, 60),
) -> pd.DataFrame:
    """构建多周期收益率特征。输入应已按资产、时间排序。"""
    out = df.copy()
    g = out.groupby(asset_col, sort=False)[close_col]

    for n in windows:
        out[f"mom_{n}"] = g.pct_change(n, fill_method=None)

    return out


def add_range_features(
    df: pd.DataFrame,
    asset_col: str = "asset",
    windows: tuple[int, ...] = (20, 60),
) -> pd.DataFrame:
    """构建不包含当前 K 线高低点的历史区间特征。"""
    out = df.copy()
    g = out.groupby(asset_col, sort=False)

    for n in windows:
        prior_high = g["high"].transform(
            lambda s: s.shift(1).rolling(n, min_periods=n).max()
        )
        prior_low = g["low"].transform(
            lambda s: s.shift(1).rolling(n, min_periods=n).min()
        )

        width = (prior_high - prior_low).where(
            (prior_high - prior_low) > 0
        )

        out[f"range_position_{n}"] = (
            (out["close"] - prior_low) / width
        )
        out[f"range_width_{n}"] = width / out["close"]

    return out


def winsorize_cross_section(
    s: pd.Series,
    lower: float = 0.01,
    upper: float = 0.99,
) -> pd.Series:
    """按当前截面分位数缩尾。"""
    if not 0 <= lower < upper <= 1:
        raise ValueError("要求 0 <= lower < upper <= 1")

    valid = s.notna()
    if not valid.any():
        return s.copy()

    lo = s.loc[valid].quantile(lower)
    hi = s.loc[valid].quantile(upper)

    return s.clip(lower=lo, upper=hi)


def cross_sectional_rank(
    df: pd.DataFrame,
    factor_col: str,
    date_col: str = "date",
) -> pd.Series:
    """按日期计算截面百分比排名。"""
    return df.groupby(date_col)[factor_col].rank(
        pct=True,
        method="average",
    )


def validate_panel(
    df: pd.DataFrame,
    date_col: str = "date",
    asset_col: str = "asset",
) -> None:
    """执行基础面板数据检查。"""
    required = {date_col, asset_col}
    missing = required - set(df.columns)

    if missing:
        raise ValueError(f"缺少必要字段: {sorted(missing)}")

    if df[[date_col, asset_col]].isna().any().any():
        raise ValueError("date 或 asset 存在缺失值")

    if df.duplicated([date_col, asset_col]).any():
        raise ValueError("(date, asset) 存在重复记录")
```

调用示例：

```python
df = df.sort_values(["asset", "date"]).copy()

validate_panel(df)

df = add_momentum_features(df)
df = add_range_features(df)

df["mom_20_winsor"] = (
    df.groupby("date")["mom_20"]
      .transform(winsorize_cross_section)
)

df["mom_20_rank"] = cross_sectional_rank(
    df,
    factor_col="mom_20_winsor",
)
```

这里的函数库只负责基础因子构建和数据检查。中性化、未来收益标签、IC 评价和组合回测建议保持为独立模块，避免把不同研究阶段耦合在一起。

## 18. 我的因子研究工作流

我会将日常研究组织为以下闭环。

### 第一步：观察市场现象

我先描述一个明确现象，而不是先写代码。例如：“价格突破前的波动区间收窄，突破后是否更容易延续？”

### 第二步：提出机制与可证伪假设

我会同时考虑延续和反转两种可能，明确什么样的数据结果会支持或否定假设。

### 第三步：定义最小可用因子

先构建最直接的变量，例如历史区间宽度、突破幅度和突破前成交量变化。不要一开始就组合十几个变量。

### 第四步：检查数据和计算时点

我会确认窗口边界、资产分组、时区、缺失值以及因子可用时间，避免把数据错误误认为市场规律。

### 第五步：生成因子数据

采用统一的命名、索引和字段类型，保存原始因子值。预处理后的因子应当能够追溯到原始因子。

### 第六步：做描述性检查

即使暂时不进行正式回测，我也会检查：

- 因子分布；
- 缺失值比例；
- 极端值；
- 时间稳定性；
- 截面分布；
- 与已有因子的相关性；
- 是否具有足够的有效观测。

### 第七步：进行正式验证

后续再开展 IC、分位数收益、交易成本、风险暴露和样本外检验。对于大量候选因子，应考虑多重检验和数据挖掘偏差。

### 第八步：维护因子版本

对每次定义变化记录版本，不覆盖旧结果。若新版本只是更换窗口、调整预处理或修正数据对齐，应能明确识别这些差异。

### 第九步：形成可复用研究资产

最终积累的不是一堆零散脚本，而是：

- 一套因子定义规范；
- 一个可测试的因子函数库；
- 一份统一的因子数据集；
- 一套可复现的数据管道；
- 一套因子元数据和版本记录；
- 一套后续评价与组合研究接口。

## 19. 术语表

| 术语 | 含义 |
|---|---|
| 因子（Factor） | 对资产特征或市场行为的定量描述 |
| 时序（Time Series） | 同一资产沿时间变化的序列 |
| 截面（Cross-section） | 同一时点不同资产之间的比较 |
| 面板数据（Panel Data） | 同时包含资产维度和时间维度的数据 |
| 动量（Momentum） | 历史价格或收益的延续特征 |
| 反转（Reversal） | 历史价格或收益的反向特征 |
| 波动率（Volatility） | 收益或价格变化的波动程度 |
| 中性化（Neutralization） | 剥离指定解释变量相关暴露的过程 |
| 缩尾（Winsorization） | 将极端值替换为分位数边界值 |
| 标准化（Standardization） | 将数据转换到可比较的尺度 |
| IC | 因子与目标变量之间的相关系数 |
| ICIR | IC 均值与 IC 波动的比值 |
| 前视偏差（Look-ahead Bias） | 历史决策使用了当时不可获得的未来信息 |
| 样本外检验（Out-of-sample Test） | 使用未参与开发或参数选择的数据检验研究结果 |
| 多重检验（Multiple Testing） | 同时尝试大量假设时出现偶然显著结果的风险 |
| 交易成本（Transaction Costs） | 手续费、滑点、价差和市场冲击等成本 |

## 结语：我真正需要掌握的不是函数数量，而是因子研究方法

我会把因子研究理解为一个从市场观察到可检验变量的过程，而不是技术指标的堆叠。

对每个候选因子，我都应该能够回答：

1. **我观察到了什么现象？**
2. **为什么它可能与未来收益、风险或交易成本有关？**
3. **我用什么数学表达式刻画它？**
4. **我计算的这个值在什么时候真正可用？**
5. **它与已有因子有什么区别？**
6. **我如何检查数据质量和计算边界？**
7. **我将如何验证它，而不是预先认定它有效？**

当这些问题都能得到清楚回答时，Python 函数只是实现工具。真正决定研究质量的，是假设是否清晰、定义是否严谨、数据是否可靠、时间是否对齐，以及验证是否足够诚实。

> **最后的原则：先解释市场现象，再定义因子；先保证计算正确，再优化性能；先保存可追溯的原始因子，再做预处理；先提出可证伪的假设，再用数据判断它是否成立。**
